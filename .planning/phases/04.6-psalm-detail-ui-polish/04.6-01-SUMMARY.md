# Phase 4.6 Plan 01: Psalm Detail Layout Restructure Summary

**One-liner:** Notation-first layout with static stanzas removed, space-y-6 tab spacing, and stanza number regex fix via `replace(/^(\d+)([A-Za-z])/, '$1 $2')`.

## What Was Built

Restructured the psalm detail page so the primary worship surface (notation player + controls) appears first, above the reference tab strip. Removed the duplicated static stanzas block that caused metrical lyrics to appear twice. Added a "No notation available" fallback for psalms with no tune assigned. Standardised all TabsContent to `space-y-6` vertical rhythm. Applied stanza number display fix in both PsalmNotationPlayer and PsalmTabs Parallel tab.

## Decisions Made

- **D-01 Notation first:** Grid (`grid-cols-1 md:grid-cols-[3fr_2fr]`) with `mb-8` placed before `<hr>` divider and `<PsalmTabs>`.
- **D-04 Remove static stanzas:** Deleted `stanzas` variable (lines 44–46) and entire `<section>` block (Metrical Lyrics h2 + stanzas.map). PsalmNotationPlayerClient is now the sole lyrics surface.
- **D-06 Null tune fallback:** `primaryTune ? <PsalmNotationPlayerClient /> : <p>No notation available…</p>` — shown when no tune is assigned to the psalm.
- **D-07 Stanza regex:** `.replace(/^(\d+)([A-Za-z])/, '$1 $2')` applied in PsalmNotationPlayer stanza split and PsalmTabs Parallel tab render. Pure display-layer fix; no DB changes.
