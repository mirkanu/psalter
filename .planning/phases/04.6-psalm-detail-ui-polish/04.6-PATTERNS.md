## Key Implementation Notes for Planner

1. **Wave order matters:** Install `sheet.tsx` via `npx shadcn add sheet` must be the first task in the SiteHeader plan — it is a hard prerequisite for the import to resolve.

2. **TabsList height override:** `tabsListVariants` CVA applies `group-data-horizontal/tabs:h-8`. The mobile sticky bar must override this with `h-auto` (or `!h-auto` if tailwind-merge doesn't win). Test at implementation time.

5. **Static stanza block removal is D-04's critical path:** `page.tsx` lines 44–46 (stanzas variable) and lines 68–84 (stanzas JSX section) must both be deleted. The notation player becomes the sole lyrics surface.

6. **Do not move Suspense boundary:** `PsalmNotationPlayerClient.tsx` already has the correct `<Suspense fallback={<Skeleton>}>` wrapper — do not modify it.
