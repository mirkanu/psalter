## Decisions Made

- Dual TabsList approach (one hidden on mobile, one hidden on desktop) chosen over a single responsive list to avoid conflicts between Tailwind h-auto overrides and shadcn's built-in h-8 on TabsList; desktop layout was completely preserved.
- Sheet w-64 side=right chosen as the most natural mobile pattern; SheetTrigger asChild used on inner `<button>` to avoid className forwarding issues.
- z-40 for the sticky tab bar keeps it below the z-50 SiteHeader and the Radix Sheet portal (which renders above all fixed stacking contexts).

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] A-/A+ font-size buttons shown in Staff notation mode**
- **Found during:** Task 3 (checkpoint — Playwright UAT and human review)
- **Issue:** The font-size increment/decrement buttons were rendered regardless of display mode. In Staff mode, abcjs renders SVG directly via `renderAbc`; the CSS `font-size` variable the buttons control has no effect on SVG output. The buttons appeared but did nothing, which is confusing UX.
- **Fix:** Added a visibility condition so A-/A+ buttons are only rendered when `displayMode === 'lyrics'`.
- **Files modified:** `src/components/PsalmTabs.tsx`
- **Verification:** Playwright UAT confirmed buttons present at 1280px in default (lyrics) mode; not visible when Staff tab active.
- **Committed in:** `d408f93` (standalone fix commit during checkpoint resolution)
