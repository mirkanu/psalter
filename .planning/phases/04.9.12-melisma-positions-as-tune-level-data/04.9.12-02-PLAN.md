  <action>
Create `scripts/migrate/extract-melisma-positions.ts` with the following behaviour:

**CLI flags:**
- `--dry-run` (default): print what would change; do NOT write to DB
- `--apply`: write changes to DB in a per-tune transaction

**Algorithm per approved tune:**

1. Split `abc_notation` into phrases using `splitOnPhraseBreaks(abc)`.
2. For each phrase body at index `i`:
   a. Find all `w:` lines in that phrase body using `extractEmbeddedWLines(phraseBody)`.
   b. Concatenate their contents (joined with space, handle multi-line w: correctly).
   c. Tokenize the concatenated content: `content.trim().split(/\s+/).filter(Boolean)`.
   d. Collect the 0-based indices where token === `'_'` → these are the melisma positions for this phrase.
   e. Append `positions[i]` = collected indices (empty array `[]` if no w: lines or no `_` tokens).
3. Build `melismaPositions: number[][] = positions` (one sub-array per phrase).
4. Build `strippedAbc`: remove ALL lines matching `/^\s*w:/` from the ABC string.
   - Do NOT use phraseBody-local logic for stripping — strip globally across the full abc string.
   - Pattern: `abc.split('\n').filter(line => !/^\s*w:/.test(line)).join('\n')`
   - Verify the stripped ABC still contains `K:` (sanity check — refuse to write if missing).
5. In `--apply` mode: update the DB row inside a transaction:
   ```typescript
   await db.transaction(async (tx) => {
     await tx.update(tunes)
       .set({
         abcNotation: strippedAbc,
         melismaPositions: melismaPositions,
       })
       .where(eq(tunes.id, tune.id))
   })
   ```

**Idempotency:** Before processing a tune, check if `melismaPositions` is already set AND the `abc_notation` has no embedded w: lines. If both are true, skip that tune with a `[SKIP]` log message.

**Output format (both modes):**

For each tune processed:
```
[DRY-RUN] Tune: Crimond (id=5)
  Phrases: 4
  Positions: [[7], [2,5], [], []]
  Stripped ABC: w-lines removed, 3 phrases had w: content
  Would update: abcNotation (stripped) + melismaPositions
```

Summary line at end: `Done. Processed: N, Skipped (already migrated): M, Errors: 0`

**Error handling:** If a tune's `abc_notation` is NULL or empty, log `[SKIP] Tune: X — no abc_notation` and continue. If `strippedAbc` is missing `K:`, log `[ERROR] Tune: X — stripped ABC lost K: header, refusing to write` and skip.

**Script entry point:** Standard top-level `async function main() { ... }` with `main().catch(console.error)`.

**Run command:**
