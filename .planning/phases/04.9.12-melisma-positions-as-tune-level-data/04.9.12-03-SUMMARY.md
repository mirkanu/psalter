# Phase 04.9.12 Plan 03: Write Path — melismaPositions API + Editor Summary

Closes the write path for melisma positions as tune-level data. Future saves from the editor store per-phrase note indices in the `melisma_positions` column rather than baking `w:` tokens into `abc_notation`. The editor can reopen approved tunes and restore underlines from the positions column without parsing embedded w: lines.

## What Changed

### `src/app/api/dev/melisma-save/route.ts`

- `SaveBody` interface gains `melismaPositions?: number[][] | null`
- Validation block rejects malformed input with HTTP 400 (threat T-04.9.12-04 mitigated)
- `updateSet` extended with `melismaPositions?: number[][] | null`; semantics: undefined = leave untouched, null = clear, array = store
- `.returning()` now includes `tunes.melismaPositions`
- Response JSON includes `melismaPositions: result[0].melismaPositions`

### `src/app/dev/melisma-editor/MelismaEditorClient.tsx`

**onSave changes:**
- Derives `melismaPositions: number[][]` by iterating phrases and recording 0-based intra-phrase indices of underlined tokens
- Builds `strippedAbc` by filtering out all `w:` lines before posting
- Posts `strippedAbc` (not `abcToSave`) as `abcNotation` field
- Posts `melismaPositions` (positions array or null) in POST body
- Post-save local state sync patches `abcNotation: strippedAbc` and `melismaPositions` on the tunes array

**tune-load useEffect changes:**
- PATH 1: if `tune.melismaPositions` is non-empty, reconstruct underline state by converting per-phrase position indices back to `globalIdx → true` map; `setSavedSyllablesPerPhrase(null)` (positions path carries no syllables)
- PATH 2: existing `parseSavedWLines` path retained as fallback for legacy tunes with embedded w: lines
- Dependency array remains `[tune]` only; uses `tune.abcNotation` directly to avoid re-render loops

### `src/app/dev/melisma-editor/page.tsx`

- `TuneOption` interface: `melismaPositions: number[][] | null` field added
- `loadTunes` DB select: `melismaPositions: tunes.melismaPositions` included
- `out.push`: `melismaPositions: r.melismaPositions ?? null` propagated to the shape
