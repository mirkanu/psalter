# Phase 04.9.6 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | vitest (per package.json `"test": "vitest"`) |
| **Config file** | `vitest.config.mts` (project root) |
| **Quick run command** | `npm run test -- <path-to-file>` (single-file feedback) |
| **Full suite command** | `npm run test && npx tsc --noEmit` |
| **Estimated runtime** | quick ~3-8 seconds; full suite ~25-45 seconds (depends on DB-backed tests in Plan 03/07) |

`npm run test` is bound to plain `vitest` (no `run`/`watch` flag), which means the CI/agent path must invoke it as `npm run test -- --run` if hanging in watch mode is observed. The current agent runner invokes vitest non-interactively which exits after the run by default.

---

## Sampling Rate

- **After every task commit:** Run `npm run test -- <task's test file>` (quick feedback)
- **After every plan wave:** Run `npm run test && npx tsc --noEmit` (full suite + type check)
- **Before `/gsd-verify-work`:** Full suite must be green AND Playwright UAT (Plan 07 Task 3) must exit 0
- **Max feedback latency:** ~10 seconds for unit tests; ~30 seconds for full suite + tsc
