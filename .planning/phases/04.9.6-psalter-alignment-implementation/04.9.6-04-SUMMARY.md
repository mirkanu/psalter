# Phase 04.9.6 Plan 04: Alignment Library Rewrite (double_length-driven) Summary

TDD rewrite of `src/lib/stanza-cycles.ts` against the canonical `tune.double_length` boolean signal (D-11). Eliminates the meter-string heuristic that caused the live DCM mis-render. Preserves the `string[][]` grid contract relied on by `NotationRenderer.tsx`'s stacking loop (B1). Retires `splitStanzaIntoPhrasePortions`; alignment now reads structured `stanza.lines` directly.

## What was built

Two atomic commits (RED + GREEN per TDD gate sequence):

1. **RED (commit `5bf468f`)** — Rewrote `src/lib/stanza-cycles.test.ts` against the new signatures:
   - `groupStanzasIntoCycles(stanzas: Stanza[], doubleLength: boolean)` with 6 it() blocks covering RENDER-01 (boolean gating), under-fill (D-12), empty input, single-stanza edge case, and a static B3 audit guard (source must not contain `'CMD'|'DCM'|'DLM'|'DSM'` literals or call `phrasesForMeter()`).
   - `mapCycleToPhraseSyllableLines(cycle: Stanza[], phrasesPerCycle: number)` with 7 it() blocks covering RENDER-02 (structured line read), B1 shape preservation (`string[][]`, T-element grid, single-string-array inner shape), under-fill padding, Line.syllables hand-override (D-03 hybrid), and a static guard against importing `splitStanzaIntoPhrasePortions`.
   - Fresh test suite ran 11 failing / 2 passing under the legacy implementation — RED confirmed.

2. **GREEN (commit `077ab39`)** — Implementation + retirement + renderer shim:
   - `src/lib/stanza-cycles.ts`: full rewrite. Imports `type { Stanza }` and `syllabifyForAbc` only; removed the `phrasesForMeter` import. `groupStanzasIntoCycles` is `cycleSize = doubleLength ? 2 : 1` with `Array.slice` pagination. `mapCycleToPhraseSyllableLines` flat-maps stanza lines across the cycle, syllabifies via `syllabifyForAbc` (or honours `Line.syllables` when present), and pads short cycles with the initial `['']` sentinel — preserving the T-element `string[][]` shape (B1).
   - `src/lib/lyrics.ts`: deleted the entire `splitStanzaIntoPhrasePortions` function (lines 75–124 of the prior file) plus the `phrasesForMeter` import (unused now). `extractVerse1`, `syllabifyForAbc`, and `buildAbcWithSyllables` untouched.
   - `src/lib/lyrics.test.ts`: removed the `describe('splitStanzaIntoPhrasePortions', …)` block (12 tests). Rewrote the 3-stanza `buildAbcWithSyllables` D-16 contract assertion to pass portion strings inline — the test now exercises the renderer-facing contract independent of the retired helper.
   - `src/components/notation/NotationRenderer.tsx` (transitional shim, B2 invariant):
     - Imported `type { Stanza }` and `phrasesForMeter`.
     - Wrapped `groupStanzasIntoCycles` call in an inline `_doubleLengthHeuristic` derived from the tune/stanza phrase ratio. Plan 05 replaces this with the canonical `tune.double_length` boolean prop.
     - Rewrote `wLinesForPhrase` with a `try/catch` shim around `mapCycleToPhraseSyllableLines(stanzaCycle, phrasesForMeter(tuneMeter))` returning `['']` on shape mismatch (since `visibleCycles` is still upstream-shaped as `string[][]` — Plan 05 rewires it to `Stanza[][]`).
     - Consumer logic (`grid[i] ?? ['']` flatMap) unchanged in shape — B1 contract intact.
