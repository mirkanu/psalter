# Phase 04.9.6 Plan 02: Structured-Lyrics Parser + Serialiser Summary

Implemented `parseLyrics` and `serialiseLyrics` in `src/lib/lyrics-structured.ts` via TDD, covering all seven F-patterns from RESEARCH and the Psalm 23 canonical case. Round-trip is lossless modulo whitespace per D-05.

## What was built

1. **`src/lib/lyrics-structured.test.ts`** (RED, commit `5034d61`) — 14 tests across 9 `describe` blocks:
   - Psalm 23 stanza 1 canonical case (D-16) — `bibleVerseRef=1` on line 0, `bibleVerseRef=2` on line 1, `undefined` thereafter
   - F-1 continuation stanza — second stanza first line has `bibleVerseRef=undefined`
   - F-2 mid-line digit with space ("6 By men...") — digit extracted, space stripped
   - F-3 mid-line digit glued to letter ("5men's sons...") — digit extracted from glued form
   - F-4 refrain — every line has `bibleVerseRef=undefined`
   - F-5 colophon — `ok=false` with `reason` containing "colophon"
   - F-6 meter mismatch — `ok=false` with `reason` containing "multiple"
   - F-7 unknown / null meter — `ok=false` with `reason` containing "unknown meter"
   - Round-trip (`it.each`) — Psalm 23 + F-1..F-4 fixtures all round-trip lossless modulo whitespace via the `NORMALISE` helper from the plan
   - Imports `{ describe, it, expect } from 'vitest'` (vitest globals=false rule)

2. **`src/lib/lyrics-structured.ts` parser + serialiser** (GREEN, commit `25746df`) — Replaced the two `throw new Error('not implemented — plan 02')` stubs with full bodies:
   - **`METRICAL_LINES`** — 21 keys covering CM/CMD/LM/LMD/SM/SMD plus 10.10.10.10.10, 66.66.88, 87.87, 76.76.D with dotted, spaced, and abbreviated variants. Includes `DCM` (the metric Phase 04.9.5 surfaced as the bug blocker — see MEMORY: Alignment-phase prerequisites).
   - **`normaliseMeter`** strips parenthetical descriptions (`"CM (common meter, 86 86)"` → `"CM"`).
   - **`resolveLinesPerStanza`** does exact lookup, then a case-insensitive substring fallback over known keys.
   - **`parseLyrics`** — returns ok=false on unknown meter or colophon detection (`^#`), flattens non-blank lines using the existing `split(/\n\s*\n/)` regex from `src/lib/lyrics.ts:22` (D-06 invariant 3), extracts the leading-digit prefix via `^(\d+)\s*(\S.*)$` (covers both F-2 and F-3), checks the F-6 invariant (line count mod meter), and chunks into stanzas with zero-based `index`.
   - **`serialiseLyrics`** — emits `${bibleVerseRef}${text}` (strict `\d+\S`, no whitespace), lines joined with `\n`, stanzas joined with `\n\n`.
