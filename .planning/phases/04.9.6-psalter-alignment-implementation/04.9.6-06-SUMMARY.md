# Phase 04.9.6 Plan 06: StanzaList Inline Verse Superscripts Summary

TDD rewrite of `StanzaList` from `string[]` to `Stanza[]`, emitting inline `<sup class="verse-number">{bibleVerseRef}</sup>` before each line that begins a new Bible verse — the one net-new visual surface of Phase 04.9.6. Existing `.verse-text` / `.verse-number` CSS classes in `globals.css` carry all sizing/typography; no new CSS introduced. NotationRenderer's three Plan-05 `stanzaStrings` adapter sites now pass the canonical `Stanza[]` directly.

## What landed

- **`src/components/notation/StanzaList.tsx`** — Prop signature changed to `stanzas: Stanza[]`. Each stanza renders as a `<p class="verse-text whitespace-pre-line">`; each line renders as a `<span>` optionally prefixed by `<sup class="verse-number">{bibleVerseRef}</sup>`. Adjacent metrical lines separated by an emitted `'\n'` text node so `whitespace-pre-line` preserves the line break visually without breaking the inline `<sup>` placement.
- **`src/components/notation/NotationRenderer.tsx`** — Dropped the `stanzaStrings` useMemo adapter. All 3 `<StanzaList stanzas={…} />` call sites (staff `renderLyricsBelow`, solfège branch, lyrics-only branch) now pass `stanzas` directly. The 3 `stanzaStrings.length > 0` / `=== 0` guards re-pointed at `stanzas.length`.
- **`src/components/notation/StanzaList.test.tsx`** — 5 RTL tests covering: superscript count for refs, omission for ref-less lines, `.verse-text` class reuse, empty-array → null, document order.
- **`vitest.config.mts`** — `include` extended to `*.test.{ts,tsx}`.
