## Decisions Made

- **149/150 counts as RENDER-08 closed**: The single failure (psalm 75) is a transient browser crash from earlyoom killing Chromium mid-`page.evaluate`. Psalm 75 passes on immediate retry. Not an alignment defect.
- **Fresh browser per psalm adopted**: The original shared-browser approach caused accumulative memory pressure and OOM kills at psalm ~52 and ~122. One Chromium process per psalm avoids this. ~14 min total runtime (vs 42 min for shared browser).
- **Production rebuild was required**: The `next start` PM2 server was running against a dev-only `.next/` directory (no `BUILD_ID`). All psalm pages returned "Could not load this psalm." until rebuild. This pre-existing issue from a prior dev session was the root cause of the 04.9.9 sweep showing only 48/150 pass.
