## Infrastructure Notes

**Production build rebuild required (Rule 3 auto-fix):**
The `next start` production server was running against a stale/incomplete `.next/` directory
that referenced a missing chunk (`0uu1dgfzd1rsc.js`), causing all psalm pages to show
"Could not load this psalm" in Playwright. Root cause: the `.next/` directory contained
only dev-mode Turbopack artifacts; no `BUILD_ID` file was present.

Fix applied: `npm run build` (required TypeScript fix first — see deviations).
Server restarted via `pm2 restart psalter`. Build verified with `cat .next/BUILD_ID`.

**Playwright sweep script improvements (Rule 2 + Rule 3 auto-fix):**
The original sweep script crashed at psalm ~52 and ~122 due to earlyoom killing the shared
Chromium browser process. The script then failed to write the JSON report.
Fix: refactored to use a fresh browser per psalm (`launchBrowser()` helper) and moved
report-writing to always execute after the psalm loop. This ensures partial results are
never lost on browser crash.
