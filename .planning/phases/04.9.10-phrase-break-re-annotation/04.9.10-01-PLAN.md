<objective>
Re-annotate all 150 tunes in the PostgreSQL DB with correct PHRASE_BREAK markers
using the Path NH character-level tokenizer that was written in Phase 04.9.8-05
but never applied to the existing dataset.

Purpose: 102/150 psalms are failing the staff alignment sweep because their
PHRASE_BREAKs were inserted at text-line boundaries (the old algorithm) rather
than at precise note-head offsets (Path NH). Running `--overwrite` on all tunes
replaces stale markers with correct ones in a single idempotent pass.

Output: All 150 tunes updated in DB; SQL spot-check confirms CM tunes have
3 markers; log files captured for audit.
</objective>

From scripts/annotate-phrase-breaks.ts:
- `insertPhraseBreaks(abc: string, n: number, noteHeadSplitPoints?: number[]): string`
  Pure function. Called by main() for each tune row.
- `getSplitPointsForMeter(meter: string | null | undefined, n: number): number[] | undefined`
  Returns note-head split positions by meter token:
    CM / 8.7.8.7 / n=4  → [8, 14, 22]
    LM / n=4            → [8, 16, 24]
    SM / n=4            → [6, 12, 20]
    7.6.7.6 / n=4       → [7, 13, 20]
    DCM / n=8           → [8, 14, 22, 30, 36, 44, 52]
    DLM / n=8           → [8, 16, 24, 32, 40, 48, 56]
    DSM / n=8           → [6, 12, 20, 26, 32, 40, 46]
    unknown meter       → undefined  (falls through to Path A line-split)
- `countNoteHeads(abc: string): number`
  Used internally. Strips info fields, grace notes, decorations; counts A-Ga-g tokens.

CLI flags (main() function):
  --dry-run    Print plan, no DB writes
  --overwrite  Strip existing % PHRASE_BREAK lines and re-annotate from scratch
  --tunes=A,B  Comma-separated tune names (optional subset filter)

DB update pattern used in main():
  drizzle(client).update(schema.tunes)
    .set({ abcNotation: updatedAbc })
    .where(eq(schema.tunes.id, tuneRow.id))

```sql
SELECT name,
       (LENGTH(abc_notation) - LENGTH(REPLACE(abc_notation, '% PHRASE_BREAK', ''))) / 14 AS marker_count
FROM tunes
WHERE meter LIKE 'CM%'
ORDER BY name
LIMIT 20;
```


All rows in the result MUST show marker_count = 3. Any row showing 0 or NULL
