## Fixed Issues

### CR-01: Off-by-one in Path B splice-index formula

**Files modified:** `scripts/annotate-phrase-breaks.ts`
**Commit:** 4e8febc
**Applied fix:** Removed `- 1` from `Math.floor((internalBars.length * k) / n) - 1` so the index formula matches the stated comment (`floor(internalBars.length * k / n) for k = 1..n-1`). Without this fix, the last phrase was consistently one bar shorter than intended.

### WR-01: OVERWRITE mode strips w: lyric lines destructively

**Files modified:** `scripts/annotate-phrase-breaks.ts`
**Commit:** 712fa95
**Applied fix:** Removed `.replace(/^w:.*$/gm, '')` from the OVERWRITE path. The OVERWRITE block now strips only `% PHRASE_BREAK` markers and collapses blank lines; `w:` lyric lines are preserved intact. Updated the comment accordingly.

### WR-02: UAT harness counts image-fallback psalms as passed

**Files modified:** `scripts/uat/verify-staff-alignment.js`
**Commit:** e0e91de
**Applied fix:** Added a `skipped` counter (initialised alongside `passed` and `failed`). The image-fallback/no-notation branch now increments `skipped` (not `passed`) and logs `SKIP` instead of `WARN`. The `summary` object written to `report.json` now includes the `skipped` field, and the console summary line reports all three counts.

### WR-04: Double-newline collapse after splice is too broad

**Files modified:** `scripts/annotate-phrase-breaks.ts`
**Commit:** e3b9e0a
**Applied fix:** Replaced the global `spliced.replace(/\n{2,}/g, '\n')` with two targeted replacements that only collapse blank lines immediately before or after a `% PHRASE_BREAK` marker. Blank lines belonging to `w:` directives or other ABC fields are no longer affected.

### WR-05: Hardcoded ABC header as 6 lines

**Files modified:** `scripts/fix-stracathro-rimington.ts`
**Commit:** ceebfbd
**Applied fix:** Replaced `abc.split('\n').slice(6).join(' ')` with dynamic `K:` line detection via `findIndex`. Music body is now extracted as everything after the first `K:` header line, regardless of how many header fields precede it. Falls back to an empty string if no `K:` line is found.
