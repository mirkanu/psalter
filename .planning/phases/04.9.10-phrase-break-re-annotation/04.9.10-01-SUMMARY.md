## Deviations from Plan

### Plan Expectation vs Actual Count

The plan stated ≥145 tunes annotated. Actual result: 134. This is not a bug — the plan's estimate was based on "150 tunes minus 5 data-gap tunes", but the actual DB has:
- 172 total tunes (not 150 — includes tunes not yet linked to psalms)
- 28 with NULL abc_notation (excluded)
- 10 with unrecognised meters (n=1, skipped)
- 5 with truncated ABC data (partial annotation)

134 is the correct annotated count for the current DB state. The acceptance criteria threshold of ≥100 for Task 1 is met (135 dry-run lines).

### --tunes Filter Pre-existing in Script

`scripts/annotate-phrase-breaks.ts` had uncommitted changes from Phase 04.9.9 work (adding `--tunes` filter flag + `inArray`/`sql` imports). These were staged and committed as part of Task 2's data commit — they were already in the working file and are correct additions referenced in the plan's interfaces section.

### DB Container Was Stopped

`psalter-db` Docker container was in `Exited (0)` state at start of execution. Started it with `docker start psalter-db` before running the script. No data loss — clean shutdown.
