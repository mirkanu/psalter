# Phase 04.9.13 Plan 01: Gear Drawer to Gear Popover Summary

Replaced the bottom-Sheet GearDrawer with a compact anchored GearPopover (top/end) featuring a two-option main toggle (Music Notes / Lyrics Only), conditional sub-toggles (Notation: Staff/Solfège, Layout: Split-leaf/Inline), a Study button navigating to /psalms/[id]/study, and a Restart tour button with identical behavior. GlassBottomBar now accepts an optional `gear` ReactNode slot. SingingView owns new `layout` state for downstream split-leaf view.
