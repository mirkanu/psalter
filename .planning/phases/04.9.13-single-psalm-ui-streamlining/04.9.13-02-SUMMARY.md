## What Changed

### Task 1: PlayMiniBar desktop right-align + abc/SoundCloud toggle + disclaimer
- `Props` interface extended with optional `soundcloudUrl?: string | null` and `tuneName?: string`
- Desktop (≥768px): floating right card via `md:ml-auto md:max-w-md md:right-4 md:rounded-lg md:shadow-lg`; centers the stanza nav area

- abc/SoundCloud toggle button (lucide Music/Radio icons) shown only when `soundcloudUrl` starts with "http"

### Task 3: Wire PlayMiniBar into /tunes/[id]
