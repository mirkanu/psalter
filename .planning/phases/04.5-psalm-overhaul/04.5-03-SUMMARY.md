## Stanza Group Logic

- `chunk(stanzas, 4)` produces groups of up to 4 stanzas
- `buildAbcWithStanzas(baseAbc, stanzaGroup)` strips existing `w:` lines then appends each stanza as a new `w:` line (one per stanza) — abcjs renders them as successive verses under the same staff
- Counter: `Stanzas ${firstNum}–${lastNum} / ${total}` (e.g. "Stanzas 1–4 / 6", "Stanzas 5–6 / 6")
- Edge case: single stanza → "Stanza 1 / 1"
- Nav buttons hidden when only one group exists or in Solfège/Lyrics-only mode

## Dynamic Import Pattern

The plan anticipated that RSC + `dynamic(ssr:false)` might fail. Turbopack (Next.js 16.2.5) explicitly rejects `ssr: false` in Server Components at build time:

> `` `ssr: false` is not allowed with `next/dynamic` in Server Components ``

**Resolution:** Created `PsalmNotationPlayerClient.tsx` as a `'use client'` file hosting the `dynamic(ssr:false)` import and the `<Suspense>` fallback. `page.tsx` (RSC) imports the wrapper, not `PsalmNotationPlayer` directly.
