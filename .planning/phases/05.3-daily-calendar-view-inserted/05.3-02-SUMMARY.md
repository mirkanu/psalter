## Decisions Made

- **buttonVariants + Link instead of Button asChild:** The project's `src/components/ui/button.tsx` uses `@base-ui/react/button` which has no `asChild` prop (unlike Radix shadcn). The existing pattern for styled link-buttons is `buttonVariants({ variant })` applied as className to a `<Link>` — established in `PsalmNav.tsx`. Applied the same pattern here.
- **Early return for null-reading branch:** Replaces nested ternary with an early return, making the component flat and readable. The null card still renders the outer `bg-muted border-l-4 border-l-primary` container per UI-SPEC.
