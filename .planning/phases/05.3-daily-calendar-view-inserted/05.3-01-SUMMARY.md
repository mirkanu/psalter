## Decisions Made

- **async main() wrapper in backfill script:** tsx runs scripts in CJS output format where top-level await is not supported. Wrapping in `async function main()` matches the pattern used in `migrate-airtable.ts` and avoids the `ERR_MODULE_NOT_FOUND` / transform error.
- **365/365 rows populated:** Airtable's "365 Days" table had complete verse-range coverage — all rows have both `Starting Verse` and `Ending Verse` fields populated. The acceptance criteria said ">100" but actual result is full coverage.
- **Worktree test execution:** Vitest include patterns in the project root don't resolve worktree paths. Tests are run via `npx --prefix /data/home/psalter vitest --root <worktree>` to pick up the updated schema.
