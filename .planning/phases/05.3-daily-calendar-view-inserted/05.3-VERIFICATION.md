### Gaps Summary

Two gaps block the phase goal:

**Gap 1 (Behavioral defect — CR-01/CR-02):** The monthly calendar grid's year state is permanently frozen at the initial year. `displayedYear` is destructured without a setter (`const [displayedYear] = ...`), and both nav handlers only call `setDisplayedMonth`. In addition, `prevMonth` returns `year: y` instead of `year: y - 1` on the January→December wrap. The effect is that navigating to any month correctly changes the month heading (e.g. "May 2026", "December 2026") but all day-of-year lookups continue using 2026. If a user navigates to "January" from a wrap, they see a "January 2026" label but the cells calculate against year 2026 — correct for this use case, but navigating backwards from January would silently show the same readings as January 2026 rather than a prior year. The Playwright UAT (which would have caught this) was not run against month-boundary navigation, and was itself never merged into the master branch.

**Gap 2 (Missing artifact):** `scripts/uat/daily-calendar-uat.js` is absent from the working tree and from all reachable git history. The file exists in orphaned worktree commit `ae8e782` (confirmed by `git show ae8e782:scripts/uat/daily-calendar-uat.js`) but was not included in the squash-merge commit `799fe26` that brought the worktree work into master. The SUMMARY and commit message claim "Playwright UAT: 6/6 pass" but the script itself cannot be recovered without cherry-picking from the orphaned commit. The plan required this script as a deliverable artifact.

These two gaps are related: the year-nav bug was flagged by the code reviewer (CR-01, CR-02) and would likely have been caught by the UAT script's month-navigation assertion if that script had been run after the bug was identified and fixed. As delivered, the calendar is functionally correct for users who never navigate past December or before January within the current session, which covers the primary use case. But the behavioral defect is real and the UAT artifact is missing from the repository.
