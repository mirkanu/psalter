## Decisions Made

- **Custom CSS grid over shadcn Calendar component:** The installed `calendar.tsx` uses `react-day-picker` which is designed for date picking UI. Psalm ref data inside each cell requires full layout control — stacked day number + psalm ref with custom today highlight. Custom `grid grid-cols-7` gives this cleanly.
- **UAT uses global `abbr` query for headers:** Scoped selectors with `:first-of-type` on `[class*="grid-cols-7"]` were unreliable in the Playwright daemon context. Since `abbr` elements only appear in the calendar day header row on this page, a global `$$eval('abbr')` is unambiguous and more robust.
- **Deploy from main checkout:** PM2 runs the app from `/data/home/psalter`. Changed files were copied from the worktree to the main checkout before `npm run build && pm2 restart psalter`. This is consistent with how previous waves deployed.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] UAT header selector was too narrow**
- **Found during:** Task 3 (first UAT run)
- **Issue:** The selector `[class*="grid-cols-7"]:first-of-type abbr` failed to match `abbr` elements in the Playwright daemon environment — the `:first-of-type` pseudo-class applied to a class attribute substring selector doesn't work as expected across browsers
- **Fix:** Changed to `$$eval('abbr', ...)` which correctly finds all 7 day-header abbreviations (only use of `<abbr>` on the /daily page)
