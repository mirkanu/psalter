</acceptance_criteria>
<action>
In SingingView.tsx:
1. Add state: `topBarHidden`, `bottomBarHidden` (boolean)
2. Add scroll listener with passive event listener:
```tsx
useEffect(() => {
  let lastScrollY = 0;
  const handleScroll = () => {
    const scrollY = window.scrollY;
    const scrollingDown = scrollY > lastScrollY;
    if (scrollY > 40) setTopBarHidden(scrollingDown);
    if (scrollY > 100) setBottomBarHidden(scrollingDown);
    lastScrollY = scrollY;
  };
  window.addEventListener('scroll', handleScroll, { passive: true });
  return () => window.removeEventListener('scroll', handleScroll);
}, []);
```
3. Pass `hidden` prop to PsalmTopBar and GlassBottomBar
4. In PsalmTopBar.tsx: add `hidden` prop, apply CSS class `data-scroll-hidden` / `data-scroll-shown`
5. In GlassBottomBar.tsx: add `hidden` prop, apply same CSS classes
6. Add CSS transitions in global CSS or component styles
7. Add onboarding tour step in OnboardingTour for scroll-hide behavior
</action>
