## Phase Goal

1. Split-leaf view layout and behavior
2. Inline solfege view with ABC rendering and approval gate
3. PlayMiniBar positioning above GlassBottomBar

## Key Design Decisions (from CONTEXT.md)

1. **Scroll-hide replaces fullscreen button** - More native iOS-like experience; top/bottom bars hide on scroll down, show on scroll up
2. **Zoom decoupling only in split-leaf** - Non-split modes preserve existing baseSize behavior for both notation and lyrics
3. **Approval gate per-tune** - Uses existing `melismaStatus` from `/api/dev/melisma-decision`; staff view always available
4. **PlayMiniBar as vertical extension** - Unified glass appearance with GlassBottomBar; fixed positioning above it
5. **Tune pagination deferred** - Not included in current plans; can be added as follow-up
