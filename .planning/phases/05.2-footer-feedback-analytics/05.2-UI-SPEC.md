## Surface Anatomy

### Site Footer

- **Placement:** `<footer>` inserted in `src/app/layout.tsx` between `<main>` and closing `</body>`, after `<Toaster />`. Spans full viewport width. Not sticky — scrolls with content.
- **Layout:** Single horizontal row on desktop; stacked column on mobile (< 768px).
- **Left cluster:** "About" link | "Copyright" link | "Feedback" link. Each is a `<button>` that opens its respective Dialog. Style: `text-sm text-muted-foreground hover:text-foreground transition-colors`.
- **Right cluster:** "Made by GSD Labs" as an `<a href="https://gsdlabs.dev">` with `target="_blank" rel="noopener noreferrer"`. Style: `text-xs text-muted-foreground hover:text-foreground`.
- **Surface:** `bg-muted border-t border-border`. Vertical padding: `py-6` (24px). Horizontal padding matches the max-w-7xl container used in SiteHeader (`px-4 sm:px-6 lg:px-8`).
- **Dark mode:** Inherits dark mode via CSS variables — no special handling needed. Footer bg-muted resolves to `oklch(0.269 0 0)` in dark mode automatically.

### About Modal

- **Trigger:** "About" button in footer.
- **Title:** "About this Psalter"
- **Content:** One short paragraph describing the site's purpose — see Copywriting Contract below.
- **Close:** shadcn Dialog default close button (X icon top-right). The shadcn `DialogClose` renders with a built-in `aria-label="Close"` — do NOT add a redundant visible label or a second close button. No explicit close button at the bottom of this modal.
- **Max width:** `max-w-md`.

### Copyright Modal

- **Trigger:** "Copyright" button in footer.
- **Title:** "Copyright Notice"
- **Content:** Inline copyright text — see Copywriting Contract below.
- **Close:** shadcn Dialog default close button only. Same accessibility note as Above modal applies — `aria-label="Close"` is provided by shadcn; no additional labelling needed.
- **Max width:** `max-w-md`.

### Feedback Modal

- **Trigger:** "Feedback" button in footer.
- **Title:** "Send Feedback"
- **Layout:** Vertical form stack with 16px gaps between fields.
- **Fields (in order):**
  1. `<Textarea>` — Label: "Your message", Placeholder: "Suggestions, feedback, or corrections…", required. `rows={4}`, `resize-none`. Font size min 16px (iOS zoom prevention — already in globals.css).
  2. `<Input>` — Label: "Name (optional)", type="text", placeholder="Your name".
  3. `<Input>` — Label: "Email (optional)", type="email", placeholder="your@email.com".
  4. `<Checkbox>` + `<Label>` — "Include current page URL" — checked by default.
- **Submit:** `<Button type="submit">` with label "Send feedback". Full-width on mobile, auto-width on desktop, right-aligned. Shows a spinner and disabled state during submission (use `useTransition` or `useState(loading)`).
- **Success state:** After successful submission, replace form content with: heading "Thank you for your feedback" + body "We'll review your message and get back to you if needed." + close button "Done". Do not close modal automatically.
- **Error state:** If submission fails, show inline error below the submit button — see Copywriting Contract. Do not clear form fields.
- **Close (X button):** shadcn Dialog default close button. `aria-label="Close"` is provided by shadcn — do NOT add a redundant visible label.
- **Max width:** `max-w-lg`.

### Admin Feedback Page (`/admin/feedback`)

- **Route:** `src/app/admin-only/feedback/page.tsx` — gated to admin by existing `admin-only` route group (Phase 05.1 middleware already handles this).
- **Layout:** Standard page with `max-w-5xl mx-auto px-4 py-8` container.
- **Page heading:** "Feedback Submissions" at `text-2xl font-semibold`.
- **Table columns:** Submitted (timestamp, formatted as `dd MMM yyyy HH:mm`), Name, Email, Page URL (truncated to 40 chars, full URL on hover via `title` attribute), Message (first 120 chars truncated with ellipsis; full message in a `<details>` or on click).
- **Empty state:** "No feedback submissions yet." centered in table body.
- **Row ordering:** Newest first (`ORDER BY created_at DESC`).

### Umami Snippet

- **Placement:** `<Script>` tag in `src/app/layout.tsx`, inside `<head>` via `strategy="afterInteractive"`. Uses Next.js `<Script>` component.
- **No UI surface:** Umami is invisible to the user — no visible change to any page. Implementation detail only; listed here so executor knows where to place it.

## Accessibility Notes

- All three footer modal triggers must be `<button>` elements (not `<a>` tags without href) — they open modals, not navigate.
- Dialog components from shadcn handle `aria-modal`, `aria-labelledby`, and focus trap automatically. No custom ARIA needed.
- The shadcn `Dialog` X close button includes a built-in `aria-label="Close"` — do NOT add a second visible "Close" label or button alongside it. Using shadcn's `DialogClose` as-is satisfies WCAG 4.1.2 for the close affordance.
- Checkbox must have an associated `<Label>` with `htmlFor` — use shadcn `<Label>` component.
- Textarea font size minimum 16px is already enforced by `globals.css` iOS zoom rule.
- Admin table must include `<th scope="col">` on each column header.
