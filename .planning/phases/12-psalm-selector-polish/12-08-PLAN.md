Deployment facts for this project (CLAUDE.md's "Docker container" line is stale — do not follow it):
- Production runs as the PM2 process `psalter` on port 3005, fronted by Cloudflare Tunnel at `https://psalter.gsdlabs.dev`.
- Deploy is `npm run build` followed by `pm2 restart psalter`.
- Known gotcha (project memory): after a PM2 restart, already-open browser tabs keep the old client bundle and silently fail on click handlers until hard-refreshed. Every verification instruction below starts from a hard refresh.
- Screenshots go to the owner via `POST http://localhost:4820/api/services/telegram/send-file` with `{"filePath": "<absolute path under /home/services/>", "caption": "..."}`.
- All browser automation goes through the shared Playwright daemon (`/home/services/playwright-daemon/client.js`). Never `chromium.launch()`.
