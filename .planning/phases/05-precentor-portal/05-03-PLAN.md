**`src/app/api/precent/[id]/items/route.ts`** (`export const dynamic = 'force-dynamic'`):
- `POST(req, { params }: { params: Promise<{ id: string }> })`: `const { id } = await params; const setId = parseInt(id); if (isNaN(setId)) return NextResponse.json({ error: 'invalid set id' }, { status: 400 })`. Parse body (try/catch → 400). Validate `typeof body.psalmId !== 'number'` → 400 `{ error: 'psalmId (number) required' }`. Optional: `tuneId` (number | null), `verseRange` (string ≤ 20 chars | null). Compute next position inside a transaction:
  ```typescript
  const result = await db.transaction(async (tx) => {
    const rows = await tx.select({ position: setItems.position }).from(setItems).where(eq(setItems.setId, setId))
    const nextPos = rows.length ? Math.max(...rows.map(r => r.position)) + 1 : 0
    const [inserted] = await tx.insert(setItems)
      .values({ setId, psalmId: body.psalmId, tuneId: body.tuneId ?? null, verseRange: body.verseRange ?? null, position: nextPos })
      .returning({ id: setItems.id, position: setItems.position })
    return inserted
  })
  return NextResponse.json({ ok: true, item: result })
  ```
