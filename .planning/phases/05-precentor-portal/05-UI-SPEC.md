## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline gaps |
| sm | 8px | Compact row padding, button icon gap |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section gaps, modal inner padding |
| xl | 32px | Layout section breaks |
| 2xl | 48px | Page-level top/bottom padding |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Touch targets (drag handles, delete icons, play icons in table rows): minimum 44px height — use `min-h-11` (44px) consistent with existing singing-view chrome pattern.
- Precenting mode amber bar: fixed height 40px (`h-10`) matching existing `GlassBottomBar` footprint convention.
- Set detail table rows: `h-14` (56px) to accommodate drag handle + two lines of content on narrow viewports.

| Role | Size | Weight | Line Height |

- Precenting mode position counter ("3/4"): `text-sm font-semibold` — tabular-nums.

## Color

Inherits project shadcn neutral palette (oklch-based CSS variables). No new design tokens are introduced.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | --background (oklch 1 0 0 light / 0.145 dark) | Page background, modal backdrop |
| Secondary (30%) | --card / --secondary (oklch 1 0 0 / 0.97 light) | Table rows, set detail card, modal surface |
| Accent — amber (10%) | Tailwind amber scale | Precenting bar, nav arrows, Start Precenting button, meter mismatch highlight |
| Destructive | --destructive (oklch 0.577 0.245 27.325) | Delete item confirmation only |

Accent (amber) reserved for exactly these elements:
1. Precenting mode bar background: `bg-amber-100 border-amber-200` (light) / `bg-amber-900/30 border-amber-700` (dark).
2. Precenting mode nav arrows: `text-amber-700` (light) / `text-amber-300` (dark).
3. "Start Precenting" button: `bg-amber-100 text-amber-900 hover:bg-amber-200 border border-amber-300` — intentionally not a filled primary button; matches roadmap "light orange" spec.
4. Meter mismatch row highlight: `bg-amber-50 dark:bg-amber-900/20` row background + `border-l-2 border-amber-400` left accent stripe + warning badge `bg-amber-100 text-amber-800 text-xs`.
5. Active/current psalm in precenting mode position indicator.

Amber is NOT used for: general interactive states, hover effects on non-precenting UI, links, or navigation items outside `/precent/[id]/sing/[pos]`.

## Layout Contracts

### `/precent` — Set List page

```
[SiteHeader — existing, with new "Precent" nav item]
[Page container max-w-4xl mx-auto px-4 py-8]
  [H1: "Precenting Sets"  |  "+ New Set" Button (right)]
  [Separator]
  [Table: Date | Type | Precentor | Actions]
    [Row × N — click row → /precent/[id]]
  [Empty state — centered, 48px top padding]
  [CreateSetForm — inline below table or Sheet, collapsed by default]
```

- Table columns: Date (date formatted "Sunday 14 June 2026"), Type ("AM Service" / "PM Service" / "Other"), Precentor ("Manuel"), Actions (open icon or row click).
- "+ New Set" button: `variant="default"` (primary filled) — "New Set" label with Plus icon.
- Row click navigates to `/precent/[id]`.

### `/precent/[id]` — Set Detail page

```
[SiteHeader]
[Page container max-w-4xl mx-auto px-4 py-6]
  [Set header card: Date | Type | Note (read-only) | Edit icon]
  [Separator — mt-6 mb-4]
  [Action bar: "Add Psalm" button (left) | "Start Precenting" button (right, amber)]
  [Set items table]
    [Column headers: # | Psalm | Verses | Meter | Tune | Actions]
    [Row × N — dnd-kit sortable; mismatch rows amber-tinted]
    [Empty state when no items]
```

- Drag handle: `GripVertical` icon (lucide), `text-muted-foreground`, left of row number.
- Row number column: 32px wide, `text-xs text-muted-foreground tabular-nums`.
- Psalm column: psalm number + short title, links to `/psalms/[id]` in new tab.
- Verses column: free text or "All" if empty; click to open inline edit input.
- Meter column: Badge `variant="secondary"` with meter string (CM, LM, SM etc.).
- Tune column: tune name or "—" if not assigned; click opens TunePickerModal.
- Actions column: Play icon (`PlayCircle`) → opens precenting mode at this position; Trash icon → opens delete confirmation Dialog.

### PsalmPickerModal

- `Dialog` with `max-w-2xl` width, `max-h-[80vh]` height, overflow-y scroll.
- Title: "Select Psalm".
- Body: `PsalmListingGrid` component embedded directly (full grid + search bar).
- After psalm selected: verse range input slides in below the grid (`Input` with placeholder "Verses, e.g. 1–3 (leave blank for all)") + "Add to Set" button.
- Close without selecting: "Cancel" text button.

### TunePickerModal

- `Dialog` with `max-w-3xl` width, `max-h-[85vh]`, overflow-y scroll.
- Title: "Select Tune" — subtitle: "Meter pre-filtered to [CM] — you can change this".
- Body: `TuneGrid` component with `initialMeter` prop set to psalm's meter.
- Clicking a tune row confirms selection and closes modal.
- No separate "Confirm" step — tune selection is immediate on row click.
- Mismatch warning does NOT appear in this modal — it appears in the set detail row after selection.

### `/precent/[id]/sing/[pos]` — Precenting Mode

```
[SiteHeader — existing]
[PrecentingBar — fixed, below SiteHeader, above psalm content]
  [← arrow (amber, hidden on pos=1)] [Label: "Precenting Mode"] [Counter: "3 / 4"] [→ arrow (amber, hidden on last)]
[SingingView — existing component, unchanged]
```

- PrecentingBar: `h-10 bg-amber-100 dark:bg-amber-900/30 border-b border-amber-200 dark:border-amber-700 flex items-center justify-between px-4`.
- Counter format: `{pos} / {total}` in `text-sm font-semibold tabular-nums text-amber-900 dark:text-amber-200`.
- "Precenting Mode" label: `text-xs font-medium text-amber-700 dark:text-amber-300 uppercase tracking-wide`.
- Nav arrows: lucide `ChevronLeft` / `ChevronRight`, `h-5 w-5`, `text-amber-700`, min touch target 44px via padding.
- Back arrow hidden (`invisible` not `hidden`) on `pos === 1` to preserve layout width.
- Forward arrow hidden (`invisible`) on `pos === total`.
- Navigating via arrows is a `next/link` client-side navigation to `/precent/[id]/sing/[pos±1]`.

## Interaction Contracts

### Drag-and-drop (dnd-kit)

- Library: `@dnd-kit/core` + `@dnd-kit/sortable` + `@dnd-kit/utilities` — pointer-event-based (works on mobile).
- Drag activation: `useSortable` per row; drag handle is the `GripVertical` icon only (not whole row).
- During drag: dragged row uses `opacity-50`; a placeholder renders at the drop target position.
- On drop: optimistic UI update (reorder state immediately) + server action to persist new `position` values.
- On server error: revert to previous order + toast error.

### Delete confirmation

- Dialog title: "Remove psalm from set?".
- Body: "This will remove [Psalm N — Title] from the set. This cannot be undone."
- Actions: "Cancel" (secondary) | "Remove" (destructive, `variant="destructive"`).

### Meter mismatch warning

- Appears as amber row highlight (row background `bg-amber-50`) + a warning badge in the Tune column: `bg-amber-100 text-amber-800 text-xs rounded px-1.5 py-0.5 ml-1` containing "Meter mismatch".
- Tooltip on hover (shadcn Tooltip): "Psalm is [CM], tune is [LM]. Choose a matching tune or proceed as arranged."
- No blocking — precentor can keep the mismatch deliberately.

### Click feedback (consistent with project-wide PERF-02 pattern)

- All buttons: CSS `:active` scale — `active:scale-[0.97] transition-transform duration-75`.
- Async mutations (create set, add item, reorder, delete): button shows disabled state + spinner (`Loader2` icon, `animate-spin`) during pending.
- `useTransition` wraps server actions; `isPending` drives spinner visibility.
- Row play icon: navigates immediately (no async); standard `:active` scale sufficient.
