  - `typeof body.date !== 'string' || body.date.trim() === ''` → 400 `{ error: 'date is required' }`
  - `body.type !== 'AM Service' && body.type !== 'PM Service' && body.type !== 'Other'` → 400 `{ error: 'type must be AM Service, PM Service, or Other' }`
  - if `body.note != null && (typeof body.note !== 'string' || body.note.length > 500)` → 400 `{ error: 'note must be a string ≤ 500 chars' }`
  - Insert: `const [row] = await db.insert(precentingSets).values({ date: body.date, type: body.type, note: body.note ?? null }).returning({ id: precentingSets.id })`. `precentorName` defaults to 'Manuel' (D-09) — do not set it.
  - `return NextResponse.json({ ok: true, id: row.id })`

Create `src/app/api/precent/[id]/route.ts` with `export const dynamic = 'force-dynamic'`:

- `PATCH(req, { params }: { params: Promise<{ id: string }> })`: `const { id } = await params; const setId = parseInt(id); if (isNaN(setId)) return NextResponse.json({ error: 'invalid id' }, { status: 400 })`. Parse body; allow updating `date` (string), `type` (validate enum if present), `note` (≤500 if present). Always set `updatedAt: new Date()`. Run `db.update(precentingSets).set(updateSet).where(eq(precentingSets.id, setId)).returning({ id: precentingSets.id })`; if result.length !== 1 → 404 `{ error: 'set not found' }`. Return `{ ok: true }`.
- `DELETE(_req, { params })`: same await params + isNaN guard. `await db.delete(precentingSets).where(eq(precentingSets.id, setId))` (set_items cascade-delete via FK). Return `{ ok: true }`.

Imports: `import { NextResponse } from 'next/server'`, `import { db } from '@/db'`, `import { precentingSets } from '@/db/schema'`, `import { eq, desc } from 'drizzle-orm'`.
