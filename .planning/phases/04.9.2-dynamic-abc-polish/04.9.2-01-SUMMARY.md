# Phase 04.9.2 Plan 01: Phrase-split, syllable-injection, and stanza-cycle library Summary

Pure-function foundation for Phase 4.9.2 dynamic ABC layout: phrase splitting on `% PHRASE_BREAK` markers, meter-to-phrase-count normaliser, per-phrase stanza-portion splitter, syllable-aligned `w:` line injector, and the D-19/D-20 stanza-cycle model that groups stanzas into tune-passes and maps each cycle onto the per-phrase w: line structure.

## Outcome

Four pure modules + colocated test files. No UI, no abcjs, no DOM. All functions deterministic and side-effect-free except the documented `console.warn` in `groupStanzasIntoCycles` for reverse meter mismatches. Every contract downstream Wave 2/3 plans need is now in place.

## D-16 / D-19 / D-20 Contract Confirmations

- **D-16** — `buildAbcWithSyllables` accepts per-phrase portions (one per stanza, not full stanzas). The lyrics.test.ts "3-stanza phrase-1 D-16 contract" case verifies each emitted `w:` line contains only that stanza's lines 1+2.
- **D-19** — `mapCycleToPhraseSyllableLines` returns a `T`-element array where element `i` is the w: line set for phrase row `i` across the cycle.
- **D-20** — `groupStanzasIntoCycles` produces `floor(T/S)`-sized cycles: CM × CM → 1 stanza per cycle; DCM × CM → 2 stanzas per cycle paired. Reverse mismatch (S > T) emits `console.warn` (verified via `vi.spyOn`) and falls back to 1-stanza cycles. `mapCycleToPhraseSyllableLines` never re-warns.
