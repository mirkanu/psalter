## Final AbcPlayer Props Interface

```ts
interface AbcPlayerProps {
  abc: string
  title?: string
  staffJpgUrl?: string | null
  solfegeJpgUrl?: string | null
  tuneName?: string
  initialMode?: 'staff' | 'solfege'
  /** Plain-text lyrics for the current stanza group, lines separated by \n */
  lyricsText?: string
  /** abcjs render scale factor; derived from --staff-base-size by parent (NOTATION-04) */
  scale?: number
}
```

`scale` is wired into:
- `abcjs.renderAbc(..., { ..., scale: scale ?? 1 })` (default applied at usage site, not at destructure).
- The render `useEffect` dependency array: `[abc, transpose, bpm, scale, stopAudio]` — changing `scale` triggers a re-render at the new size.

The previously inline `<style dangerouslySetInnerHTML={{ __html: noteHighlightStyle }} />` JSX and `noteHighlightStyle` const are fully removed from `AbcPlayer.tsx`.

## FullscreenOverlay Final Signature

```tsx
// src/components/notation/FullscreenOverlay.tsx
'use client'

interface FullscreenOverlayProps {
  open: boolean
  onClose: () => void
  /** Optional sticky bar pinned to the viewport bottom (height: 48px). */
  bottomBar?: ReactNode
  children: ReactNode
}

export function FullscreenOverlay(props: FullscreenOverlayProps): JSX.Element | null
```

Behaviour:
- `open === false` → returns `null` (nothing rendered).
- `open === true` →
  - Renders `<div role="dialog" aria-modal="true" class="fixed inset-0 z-50 bg-background overflow-auto p-4 pb-20">{children}</div>`.
  - If `bottomBar` provided, also renders `<div class="fixed inset-x-0 bottom-0 h-12 bg-background border-t flex items-center justify-between px-4 z-50">{bottomBar}</div>`.
  - Adds a window keydown listener — Escape calls `onClose`.
  - Sets `document.body.style.overflow = 'hidden'`; restores previous value on unmount/close (cleanup).

No native Fullscreen API (iOS Safari does not support it for non-video elements — Pitfall 3).

## Consumer Compatibility

`AbcPlayerSection` and its usages (e.g. `/tunes/[id]/page.tsx`) do NOT pass `scale`. Because `scale` is optional and defaults to `1` inside `renderAbc`, the existing tune page renders unchanged. The render `useEffect`'s `scale` dep is `undefined` and stable across re-renders, so no extra renders are triggered.
