### `src/lib/lyrics.ts` (extend — `buildAbcWithSyllables`)

**Analog A (in-file):** existing `syllabifyForAbc()` (lines 43-71) — keep, reuse.
**Analog B (function to relocate):** `src/components/PsalmNotationPlayer.tsx` `buildAbcWithStanzas` (lines 23-33):

```tsx
function buildAbcWithStanzas(baseAbc: string, stanzaGroup: string[]): string {
  // Strip w: lines then collapse blank lines — blank lines in ABC mean "new tune"
  // which causes abcjs to only render the first voice line
  const withoutW = baseAbc.replace(/^w:.*$/gm, '').replace(/\n\n+/g, '\n').trim()
  const wLines = stanzaGroup.map((s) => `w: ${s.replace(/\n/g, ' ')}`).join('\n')
  return `${withoutW}\n${wLines}`
}
```

**Phase 04.9.2 extension** (per D-12, D-13): wrap each stanza in `syllabifyForAbc()` before the `w:` prefix. Verse number per D-17: prepend Unicode superscript or `<sup>` outside the abc string (abcjs `w:` doesn't render HTML; therefore verse number goes into the surrounding lyrics-only text-render path, not the `w:` line). For `w:` line, prepend the digit directly (abcjs treats a leading digit in a `w:` token as a regular character) — confirm in unit test.

**Test file analog:** `src/lib/lyrics.test.ts` (existing — `extractVerse1`, `syllabifyForAbc` tests). Extend with `buildAbcWithSyllables` cases.
