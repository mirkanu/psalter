## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] renderSnippet used `<b>` but Playwright test expects `<strong>`**
- **Found during:** Post-task verification (running PLR-02 test)
- **Issue:** Wave 0 test stub `test-plr-02.js` selects `[data-psalm-box] strong`, but Task 1 plan spec said to use `<b>`. PLR-02b would fail with 0 bold matches.
- **Fix:** Changed `renderSnippet` to emit `<strong>` elements; added `[data-snippet] strong` to globals.css alongside existing `b` rule
- **Files modified:** `src/components/PsalmNumberBox.tsx`, `src/app/globals.css`
- **Commit:** `a6ae292`

**2. [Rule 3 - Blocker] DB password mismatch prevented build**
- **Found during:** Task 3 verification (npm run build)
- **Issue:** `psalter-db` container running with stale POSTGRES_PASSWORD; `.env` has `postgres`; build's static generation failed with auth error on `/explore/authors/[author]`
- **Fix:** `docker exec psalter-db psql -U postgres -d psalter -c "ALTER USER postgres PASSWORD 'postgres';"` — restored .env password
- **Files modified:** None (runtime fix)
- **Commit:** N/A (infra fix, not code change)
