## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inner padding |
| sm | 8px | Psalm box inner padding (compact mode), gap between psalm number and meter label |
| md | 16px | Default psalm box padding, search bar horizontal padding, page horizontal gutter |
| lg | 24px | Section spacing between search bar and Advanced panel, between Advanced panel and grid |
| xl | 32px | Page vertical padding top/bottom |
| 2xl | 48px | Major section breaks (page header to search bar) |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Psalm number boxes: minimum touch target 44px × 44px on mobile (accessibility floor).
- Advanced panel internal rows: 12px gap between checkboxes and meter dropdown (between sm and md — acceptable at 12px for compact grouped controls).
- Grid gap: 8px (`gap-2`) — tighter than standard `gap-4` to maximise box density.

## Layout Contract

### Grid density (PLR-01)

- Default grid: `grid-cols-6 sm:grid-cols-8 md:grid-cols-10 lg:grid-cols-12 xl:grid-cols-15`
- This places all 150 psalms in 10–15 columns at typical desktop widths — the majority visible above the fold.
- Box minimum size: `min-w-[44px]` — enforces touch target floor.
- Box aspect ratio: 1:1 square by default (no first-line, no snippet). Use `aspect-square` or fixed `h-12` (48px) at mobile, `h-14` (56px) at desktop.
- When "Show first line" is active: boxes grow to auto height — remove `aspect-square`, add `py-2 px-2` inner padding. Grid columns reduce: `grid-cols-4 sm:grid-cols-6 md:grid-cols-8 lg:grid-cols-10`.
- When a match snippet is injected: boxes grow to auto height. Same reduced column count as first-line mode.

### Page layout (top to bottom)

```
[Page header: "Psalms" h1 + subtitle]   ← 24px margin below
[Search bar (full width)]               ← 16px margin below
[Advanced Filters toggle button]        ← 0px margin above (adjacent to search)
[Advanced panel (conditional)]          ← 16px margin below when open
[Psalm grid]
```

### Search bar spec

- Full width: `w-full max-w-none` — spans the content column.
- Left icon: `Search` (lucide, 16px, `text-muted-foreground`) inside the input padding.
- Right icon: `X` (lucide, 16px) appears only when query is non-empty — clears on click. Must have `aria-label="Clear search"`.
- Placeholder: "Search by psalm number or keyword…"
- No search button — filters on every keystroke (`onChange`).
- `autoFocus` on page load.
- `type="search"` for mobile keyboard optimisation.

### Advanced panel spec

- Toggle button: `<Button variant="ghost" size="sm">` — label "Advanced Filters" with `ChevronDown` (collapsed) / `ChevronUp` (expanded) icon. 14px text, weight 400.
- Panel renders immediately below the toggle with `8px` top gap.
- Panel background: `bg-muted rounded-lg px-4 py-3`.
- Internal layout: flex row, `gap-6`, wraps on mobile.
  - Item 1: Checkbox + label "Show first line"
  - Item 2: Checkbox + label "Show meter"
  - Item 3: `Select` for meter filter — label "Meter:" inline before the trigger, trigger width `w-40`.
- All three controls are visible simultaneously when Advanced is open — no sub-accordion.
- Default state: Advanced collapsed, all three controls at default (unchecked / "All meters").

## Interaction Contract

### Search — number input (PLR-02)

- Detection: query is purely numeric (regex `/^\d+$/`).
- Behaviour: Sort all 150 psalms by numeric distance from the typed number (`Math.abs(psalm.id - query)`). Nearest first. All psalms remain visible (no filtering).
- Top result: psalm whose `id === query` exactly (if it exists) — or nearest numeric match.
- No snippet is injected in number mode.

### Search — text input (PLR-02)

- Detection: query contains at least one non-numeric character.
- Behaviour: Client-side full-text search against pre-loaded psalm data (first line + a short KJV excerpt stored in the data payload from the RSC).
- For each matching psalm: inject the best-matching line as a snippet below the psalm number. Bold the exact search term within the snippet using `<strong>` or a `<span className="font-bold">`.
- Sort: psalms with exact-word match in first line first; then partial matches; then KJV matches. Non-matching psalms are hidden (removed from rendered output).
- Top result: first psalm in the sorted result list — receives `border-primary border-2 bg-primary/5` styling.
- Snippet copy: truncate at 80 characters. Append "…" if truncated.

### Enter key navigation (PLR-02)

- `onKeyDown` handler on the search input: if `key === "Enter"` and at least one result exists, use `router.push(`/psalms/${topResult.id}`)` immediately.
- No confirmation, no delay.

### Advanced panel interactions (PLR-03)

- "Show first line" checkbox: toggling instantly resizes all visible psalm boxes to include `firstLine` text (or hides it). No server fetch — data already in client state.
- "Show meter" checkbox: toggling instantly shows/hides meter label in box top-right.
- Meter filter dropdown: selecting a meter value immediately hides all psalm boxes whose meter does not match. "All meters" resets. Compatible with active search — both filters compound (AND logic).

### Click feedback (all interactive elements)

- Psalm boxes: `active:scale-[0.97]` + `transition-transform duration-100` — already established in `PsalmCard`, carry forward.
- Search input: shadcn Input focus ring (`ring-2 ring-ring`) — default from shadcn, do not override.
- Advanced Filters toggle: `active:scale-[0.98]` on the Button.
- Checkboxes: shadcn Checkbox component provides built-in checked animation via `tw-animate-css`.

## Accessibility Contract

- Search input: `aria-label="Search psalms"` (label is visually replaced by placeholder + icon).
- Search clear button: `aria-label="Clear search"` on the `X` icon button — required because the button has no visible text label.
- Advanced panel: `aria-expanded={open}` on the toggle button; `id="advanced-panel"` + `aria-controls="advanced-panel"` on the toggle.
- Psalm boxes: `<a>` elements (via `next/link`) — psalm number is the accessible name. Add `aria-label={`Psalm ${id}`}` to ensure screen readers announce number only (not meter label or snippet).
- Top result box: `aria-current="true"` when search is active.
- Checkboxes: shadcn Checkbox associates label via `htmlFor` — ensure IDs are `show-first-line` and `show-meter`.
- Meter select: `aria-label="Filter by meter"`.
- Colour contrast: all text on `--card` background — `--foreground` (oklch 0.145) on white passes WCAG AA at all sizes. `--muted-foreground` (oklch 0.556) on white at 14px regular ≈ 4.5:1 — passes WCAG AA normal text threshold. No contrast exemptions required.
