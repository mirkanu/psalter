## Spacing Scale

Declared values (multiples of 4 only). All tokens map to Tailwind utilities.

| Token | Value | Tailwind | Usage |
|-------|-------|----------|-------|
| xs | 4px | `p-1` / `gap-1` | Icon gaps, badge padding, inline spacing |
| sm | 8px | `p-2` / `gap-2` | Compact element spacing, button icon gaps |
| md | 16px | `p-4` / `gap-4` | Default element spacing, card body padding |
| lg | 24px | `p-6` / `gap-6` | Section padding, card outer gap |
| xl | 32px | `p-8` / `gap-8` | Layout container horizontal padding |
| 2xl | 48px | `py-12` | Major section breaks (homepage hero top/bottom) |
| 3xl | 64px | `py-16` | Page-level vertical rhythm |

Exceptions:
- Header height: 56px (not a multiple of 4 spacing token — fixed height for sticky nav bar, not a spacing gap)
- Touch targets on psalm cards and nav links: minimum 44px height (accessibility requirement)
- Daily plan "today" highlight row: 4px left border accent stripe, `pl-3` (12px) visual indent

## Typography

All sizes use Geist Sans. Geist Mono is used only for psalm numbers in the card grid and detail header.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 (regular) | 1.5 | Paragraph text, KJV verses, Haddington intro, topic descriptions |
| Label | 14px | 400 (regular) | 1.4 | Card metadata (meter badge, book label), tab labels, nav links |
| Heading | 20px | 600 (semibold) | 1.2 | Psalm card first line, section headings within tabs, tune page title |
| Display | 28px | 600 (semibold) | 1.15 | Psalm detail page title (Bible title), homepage "Today's Reading" heading |

Psalm numbers: 14px Geist Mono, weight 400 (regular), `tabular-nums`. Used in psalm card (top-left), daily plan list, and psalm detail header alongside the Bible title. Geist Mono at 400 with `tabular-nums` provides sufficient visual distinction at 14px without a third weight.

Source: CONTEXT.md (Geist font, shadcn Nova preset) — sizes defaulted to 8-point-compatible scale.

## Color

All color values use the existing CSS variables from `src/app/globals.css` (Nova neutral preset, oklch color space). No new color tokens introduced in Phase 2.

| Role | CSS Variable | Approx Value | Usage |
|------|-------------|--------------|-------|

| Accent (10%) | `--primary` | oklch(0.205 0 0) — near-black | Reserved for: today's reading highlight border, active tab indicator underline, "Read Psalm {N}" link on homepage card |

Accent reserved for:
1. Today's reading card left border stripe on `/daily`
2. Active tab underline indicator on psalm detail tabs

Border color: `--border` (oklch(0.922 0 0) — light gray). Used on psalm cards, tab separator, header bottom border.

Muted foreground: `--muted-foreground` (oklch(0.556 0 0) — medium gray). Used on metadata labels: meter, book name, psalm number on cards.

Source: CONTEXT.md ("neutral stone/slate palette, calm devotional tone") + `globals.css` (confirmed existing tokens).

## Page-Level Layout Contracts

### Header (all pages)
- Sticky top, `z-50`, height 56px
- Background: `--background` with `border-b border-border`
- Left: site name "CPRC Psalter" — 16px semibold, links to `/`
- Right: three nav links — "Psalms" (`/psalms`) · "Tunes" (`/tunes`) · "Daily Plan" (`/daily`) — 14px regular
- Active nav link: `--primary` text color + bottom border 2px `--primary`
- Mobile: hamburger menu not required in Phase 2 (desktop-first, responsive wrapping acceptable)

### Homepage (`/`)
- Two-column layout at `lg` breakpoint (≥1024px); single column on mobile
- Left/primary: "Today's Reading" card — day number, psalm number (linked), psalm title, first verse of the day's psalm
- Right/secondary: Psalm quick-search widget — input field + icon button (lucide `Search` icon, `aria-label="Find Psalm"`) for psalm number lookup only (Phase 3 adds full search)
- Vertical spacing: `py-12` above the two-column block, `gap-8` between columns

### Psalm List (`/psalms`)
- Page title: "Psalms" — 28px semibold, `mb-6`
- Filter bar: Book dropdown (shadcn Select) left-aligned, `mb-6`
- Grid: `grid-cols-2 sm:grid-cols-3 md:grid-cols-4 lg:grid-cols-5`, `gap-4`
- Card dimensions: auto height, min height 80px, `p-4 rounded-lg border border-border`
- Card content: psalm number (top-left, 14px Geist Mono muted), first line (16px regular, 2 lines max, truncate), meter badge (bottom-right, 12px badge)
- Card hover: `hover:border-primary hover:shadow-sm` transition

### Psalm Detail (`/psalms/[id]`)
- Page header: psalm number (14px Geist Mono muted) + Bible title (28px semibold) + book badge
- Tabs: Overview · Lyrics · Study · Messianic — shadcn `Tabs` component, `?tab=` URL param for deep linking
- If psalm has no messianic data: Messianic tab renders with empty state (do not hide the tab — keep navigation consistent)
- Tab content padding: `pt-6`
- **Overview tab**: Haddington intro paragraph (16px, `text-muted-foreground`), then KJV text as numbered verses (16px regular, verse number in Geist Mono muted)
- **Lyrics tab**: Primary Scottish Psalter version — each stanza as a `<p>` block, `gap-4` between stanzas. Additional versions in collapsed `<details>` below. Associated tune(s) listed at bottom with link chips to `/tunes/[id]`
- **Study tab**: Section headings (20px semibold), Nave's topics as badge list, doctrinal cross-references as a simple list
- **Messianic tab**: Classification label, NT verification text, messianic verses list

### Tune Detail (`/tunes/[id]`)
- Page header: tune name (28px semibold) + meter badge
- Score image: full-width `<img>` capped at `max-w-2xl mx-auto`, `rounded-md border border-border`; aspect ratio unconstrained (JPG from volume); `object-contain`
- Below image: YouTube embed (if url exists) in 16:9 `aspect-video` container
- Links: psalm(s) using this tune — listed as card chips

### Daily Plan (`/daily`)
- Page title: "Daily Reading Plan" — 28px semibold
- Auto-scroll to today's row on page load (client component, `scrollIntoView` on mount)
- List: 365 rows, `divide-y divide-border`
- Each row: day number (Geist Mono, 14px muted, `w-12`), psalm number + title linked to `/psalms/[id]`, `py-3`
- Today's row: `bg-muted`, `border-l-2 border-primary`, `pl-3` visual distinction
- "Today" badge next to the day number on the highlighted row

## Interaction Contracts

### Tab deep-linking
- Use `?tab=overview|lyrics|study|messianic` query param
- Default (no param): Overview tab active
- Tab changes update URL without full navigation (`router.replace`, shallow)

### Psalm card navigation
- Entire card is clickable (wrap in `<Link>`)
- CSS `:active` scale: `active:scale-[0.98]` transition for tactile feedback
- Note: Phase 6 adds full `useTransition` pending indicators; Phase 2 uses native link navigation

### Daily plan scroll
- On `/daily`, a Client Component wrapper runs `useEffect` → `document.querySelector('[data-today]').scrollIntoView({ behavior: 'smooth', block: 'center' })` on mount
- `data-today` attribute placed on today's row

### Static rendering
- `/psalms`, `/psalms/[id]`, `/tunes/[id]`, `/daily/[day]` all use `generateStaticParams`
- `/daily` (full 365 list) is also statically rendered — no runtime DB query; today detection is client-side via `new Date()`
