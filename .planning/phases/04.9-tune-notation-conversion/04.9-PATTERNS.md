**Claude vision call pattern** — from `/tmp/solfege-spike.js` (lines 44–84), adapted to SDK:

```typescript
async function callVision(imagePaths: string[], prompt: string, model: string): Promise<string> {
  const imageBlocks = imagePaths.map(p => ({
    type: 'image' as const,
    source: {
      type: 'base64' as const,
      media_type: 'image/jpeg' as const,
      data: fs.readFileSync(p).toString('base64'),
    },
  }))

  const response = await client.messages.create({
    model,
    max_tokens: 2000,
    messages: [{
      role: 'user',
      content: [...imageBlocks, { type: 'text', text: prompt }],
    }],
  })

  return (response.content[0] as { type: 'text'; text: string }).text
}
```

The spike (lines 44–85) used raw `fetch()`. The production script uses `@anthropic-ai/sdk` for typed interface and built-in retry. The content array shape is identical.

**Validation before write pattern** — re-validate ABC string with `abcjs.parseOnly()` before each DB write (defensive second pass, since JSON may be from a prior run):

```typescript
const abcjs = (abcjsModule as any).default ?? abcjsModule

function validateAbc(abcStr: string): { valid: boolean; warningCount: number } {
  const result = abcjs.parseOnly(abcStr)
  const tune = result[0]
  const hasNotes = tune.lines?.some((l: any) =>
    l.staff?.some((s: any) => s.voices?.some((v: any) => v.length > 0))
  )
  const warnings = tune.warnings ?? []
  return { valid: hasNotes && warnings.length === 0, warningCount: warnings.length }
}
```

### slugifyTuneName
**Source:** `scripts/download-tunes.ts` lines 12–16 (exported function)
**Apply to:** `scripts/ocr-solfege.ts` — import, do not copy.

```typescript
export function slugifyTuneName(name: string): string {
  return name
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-|-$/g, '')
}
```

`scripts/backfill-tune-jpgs.ts` lines 10–12 contains a local copy of the same function (named `slugify`). The new OCR script must use the canonical export from `download-tunes.ts`, not this copy, to guarantee consistency.
