## Pre-Discussion Spike

A live spike was run during the discuss session on 3 representative solfège images (Dundee, Old 100th, French) using Claude Opus via the Anthropic API. Findings:
- LLM successfully identified soprano line in 4-part SATB tonic sol-fa images
- Correctly read DOH key from header and applied chromatic accidentals (e.g. `se` → `^G`)
- Minor rhythm inaccuracy: held note durations slightly underestimated (`c3` instead of `c4` for whole notes)
- Key discrepancy noted: 5 existing hand-crafted ABCs are in G major; generated ABCs will use the actual printed key
- Verdict: approach is viable, proceed with planning
