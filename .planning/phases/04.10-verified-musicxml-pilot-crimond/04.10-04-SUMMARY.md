## Rollback Recipe (verbatim, for Plan 05 sing-test failure)

```bash
# Restore pre-update Crimond ABC (uses psql dollar-quoting to handle any internal quotes):
docker exec -i psalter-db psql -U postgres -d psalter -c \
  "UPDATE tunes SET abc_notation = \$\$$(cat scripts/uat/baselines/crimond-abc-rollback.txt)\$\$ WHERE name='Crimond';"

# Rebuild and restart:
cd /data/home/psalter && npm run build && pm2 restart psalter

# Verify rollback (DEPLOY-PROOF in reverse — the old 183-char ABC has no embedded w-lines,
# so the page will fall through to the heuristic path):
docker exec psalter-db psql -U postgres -d psalter -tAc \
  "SELECT LENGTH(abc_notation), abc_notation LIKE '%w:%' FROM tunes WHERE name='Crimond';"
# Expected: 183|f
```

The captured rollback ABC is 184 bytes on disk (the `psql -tA` output adds one trailing newline; this is harmless inside dollar-quoting and matches the original 183-char DB value byte-for-byte once trimmed). Reverting takes <1 minute including build.
