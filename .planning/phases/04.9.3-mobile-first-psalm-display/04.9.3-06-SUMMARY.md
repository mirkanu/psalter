# Plan 04.9.3-06 — UAT + Human Verify + Follow-on Fixes

## What was built (and rebuilt)

This plan started as the Playwright UAT runner for the new singing view but expanded into a 14-fix iterative loop driven by real-world user UAT (5 rounds of feedback against the live production URL at https://psalter.gsdlabs.dev). The final shipped singing view differs in important ways from the UI-SPEC (per user override) but delivers on the underlying MOBILE-01/02/03 phase requirements.

### UAT pass (autonomous tasks)

1. **UAT 01 — default mobile layout @ 375px** (`f6cc4e4`): asserts SiteHeader/top-bar/sub-bar/FAB/no-tabs structure on /psalms/23.
2. **UAT 02 — FAB sheet view-mode switching** (`3941c51`): asserts FAB sheet opens, contains Staff / Lyrics only / Solfège radio group, and view-mode persists via `data-view-mode` attribute on `[data-notation-body]`.
3. **MOBILE-03 production bug discovered & fixed**: Plan 01's AbcPlayer hardening did not actually clamp abcjs SVG width. abcjs ignored `staffwidth` for dense SATB+lyrics content and emitted a 722px SVG inside a 375px viewport. Fix in `49e1aa2` (abcjs `responsive: 'resize'`).
4. **UAT 03 — overflow / resize / orientationchange** (`db4c47c`): asserts SVG `boundingClientRect().width ≤ viewport` at 375 and 768, including after dispatched `orientationchange`.
5. **UAT tune-switch** (`76d5b31`): asserts TuneSwitcherSheet → tap alt tune → URL gets `?tune=NN`, sheet closes, notation re-renders without remount.
6. **Regression check** (`7c78eb7`): `/psalms/23/study` still returns 200 and renders `[role="tablist"]`.

### Final singing view contract (as shipped)

- Global SiteHeader visible (logo + Psalms / Tunes / Explore / Daily Plan + search + hamburger).
- Sticky PsalmTopBar (`← Psalm N →`) and TuneSubBar (`Tune (M): TuneName ✎`) below SiteHeader.
- Notation body with chromeless rendering: no in-page audio chrome, no view-mode toggle on canvas (lives in FAB).
- Canvas chrome row directly below notation: A− / size value / A+ / stanza nav (`‹ Stanzas N/M ›`).
- FAB bottom-right opens bottom sheet with View / Audio / About sections.
- Staff mode: no vertical page scroll, notation fits viewport via responsive viewBox.
- Lyrics-only / Solfège modes: page scroll allowed.
- Legacy 7-tab study surface preserved at `/psalms/[id]/study` with `← Back to singing view` link.

### Trade-offs accepted

- At larger zoom levels in Staff mode, the bottom system's lyrics may clip from the no-vertical-scroll constraint — accepted to keep the singing view a fixed-viewport instrument.
- abcjs scale parameter is overridden via staffwidth-inverse computation; smaller scales would normally absorb visible growth via viewBox. Trade-off: A+/A− works visibly at the cost of using abcjs in a non-idiomatic way.
- UI-SPEC deviations on A−/A+ placement and SiteHeader visibility are explicit user overrides; UI-SPEC was not amended retroactively but the deviations are documented above.
