## What Changed

### AbcPlayer (Task 1)

Four surgical edits:

1. Outer wrapper className: `w-full space-y-3` → `w-full max-w-full overflow-x-hidden px-2 space-y-3`.
2. `staffwidth: staffWidth || 600` → `staffwidth: Math.max(0, (staffWidth || 600) - 16)` (compensates for the new `px-2`).
3. ResizeObserver gained a ≥8px width-delta threshold; effect deps changed `[]` → `[staffWidth]`.
4. New `useEffect([staffWidth])` adds `orientationchange` and `visualViewport.resize` listeners with rAF + 150ms debounce + the same ≥8px threshold — required because iOS Safari's ResizeObserver does not fire reliably on URL-bar / orientation transitions.

### /psalms/[id]/study (Task 2)

Verbatim clone of `/psalms/[id]/page.tsx`'s data flow (same `generateStaticParams`, same active-version resolution, same alternate-tune enrichment, same JPG-derivation), rendering `<PsalmTabs>` under an h1 suffixed with "— Study". Build prerenders 195+ slugs at `.next/server/app/psalms/[id]/study/`, mirroring the default route's slug surface.

### Playwright UAT stubs (Task 3)

All four scripts:
- Use `require('/usr/lib/node_modules/playwright')` + `executablePath: '/tmp/pw-browsers/chromium-1217/chrome-linux/chrome'` + `args: ['--no-sandbox']` per `CLAUDE.md`
- Default viewport 375×812 (UAT-03 also resizes to 768×1024)
- Target `http://localhost:3005`
- Skip gracefully (exit 0 + warning) if the dev server is unreachable
- 90s global timeout; PASS → exit 0, FAIL → exit 1, TIMEOUT → exit 2
- Capture screenshots under `scripts/uat/screenshots/mobile-*.png`

Coverage:
- **01** — Asserts `[data-singing-topbar]`, `[data-singing-subbar]`, `[data-singing-fab]` each count == 1, and `[role="tablist"]` count == 0.
- **02** — Opens FAB, asserts three view buttons (Staff / Lyrics only / Solfège) inside `[role="dialog"][data-singing-fab-sheet]`, selects "Lyrics only", asserts the sheet auto-closes within ~1.5s and `[data-view-mode="lyrics"]` becomes present.
- **03** — `document.documentElement.scrollWidth === window.innerWidth` at 375, 768, and after a synthetic `orientationchange`. SVG bounding-box width stays ≤ viewport width at 375, grows on resize to within ±40px of `innerWidth-16` at 768.
- **tune-switch** — Opens `[data-tune-switcher-sheet]` from the sub-bar, picks a non-current `[data-tune-slug]`, asserts URL gets `?tune=` and `[data-tune-name]` text changes without `[data-notation-body]` remount.

These currently fail because the asserted selectors do not yet exist — that is the intentional RED state Plans 02–05 will turn GREEN.
