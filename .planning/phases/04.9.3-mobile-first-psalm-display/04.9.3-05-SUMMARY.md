## What Changed

### src/db/queries/psalms.ts (Task 1)

Two new exports added; existing exports untouched.

- `getEditoriallyLinkedTuneIdsForPsalm(psalmId): Promise<Set<number>>` — joins `psalmVersionTunes` → `psalmVersions` and returns the set of `tuneId`s linked editorially to ANY version of the given psalm. SingingView uses this set to split TuneSwitcherSheet's Recommended vs Other lists.
- `fetchPsalmListRows(): Promise<PsalmRow[]>` — the canonical query that produces the row shape consumed by `<PsalmListingGrid>`. Body moved verbatim from `/psalms/page.tsx`'s previous inline implementation (same select columns, same sort, same row mapping). `/psalms/page.tsx` now imports the helper; its rendered output is byte-identical to before.

### src/components/singing/SingingView.tsx (Task 2 — new file, 223 lines)

Client root. Owns:

- `viewMode` (`'staff' | 'solfege' | 'lyrics'`) hydrated from `localStorage['psalter-score-mode']`
- `baseSize` (number) hydrated from `localStorage['psalter-staff-size']`, with mobile default 13 / desktop default 14 per UI-SPEC §3
- Both pieces of state are persisted via `useEffect` gated behind a `mounted` flag (prevents clobbering real values with defaults during the pre-hydration window)
- Sheet open/close state for PsalmSelectorSheet + TuneSwitcherSheet

Derives:

- `allTuneOptions` = primary + alts (de-duplicated) — used to whitelist `?tune=N`
- `overrideTune` = `?tune=` resolution against the whitelist (returns null when invalid/absent)
- `activeTune` = `overrideTune ?? primaryTune`
- `tuneSections` = `{ current, recommended, other }` where recommended = alts whose id is in `editoriallyLinkedTuneIds`, other = the rest; both sorted alphabetically

Composes:

```
<div data-singing-view>
  <PsalmTopBar prev next currentSlug psalmId onOpenPsalmSelector />
  <TuneSubBar tuneName meter onOpenSwitcher />
  <main data-notation-region overflow-x-hidden height=calc(100dvh-88px)>
    {abc
      ? <NotationRendererClient {...controlled} chromeless={true}/>
      : <empty state>}
  </main>
  <PsalmActionsFAB psalm meter studyHref viewMode onViewModeChange abcForAudio/>
  <PsalmSelectorSheet open onOpenChange psalms={psalmListRows}/>
  <TuneSwitcherSheet open onOpenChange sections meterLabel/>
</div>
```

Inline `<style>` block inside `<main>` adds the ≥768px media-query override (`100dvh - 100px`) — there is no Tailwind variant for this calc() so the inline style stays scoped to `[data-notation-region]`.
