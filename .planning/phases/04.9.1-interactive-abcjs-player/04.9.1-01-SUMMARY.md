## What Was Built

### AbcPlayer.tsx (src/components/AbcPlayer.tsx)

`'use client'` interactive player component with:

- **Render effect** — reruns on `abc`, `transpose`, `bpm` changes; clears prior audio/SVG; calls `abcjs.renderAbc` with `responsive:'resize'`, `add_classes:true`, `visualTranspose`, `defaultTempo`
- **Play handler** — creates fresh `abcjs.synth.CreateSynth`, calls `init + prime`, then `synth.start()` + `timingCallbacks.start()` simultaneously
- **Pause handler** — calls `synth.pause()` + `timingCallbacks.stop()`, clears note highlights
- **highlightEvent** — removes `abcjs-current-note` class from previous elements, adds to current `ev.elements` nodes; detects end-of-tune when `!ev || !ev.elements`
- **Note highlight CSS** — injected via `<style dangerouslySetInnerHTML>`: `.abcjs-current-note { fill: #2563eb !important }`
- **Controls** — Play/Pause button, Key (transpose) Select (-6..+6), BPM -/+ buttons (40-200, step 5), Show original toggle (swaps to staffJpgUrl/solfegeJpgUrl `<img>`)
- Props: `abc`, `title`, `staffJpgUrl`, `solfegeJpgUrl`, `tuneName`, `initialMode`

### AbcPlayerSection.tsx (src/components/AbcPlayerSection.tsx)

`'use client'` wrapper with `dynamic(() => import('@/components/AbcPlayer'), { ssr: false })` + `<Suspense>` skeleton — safe for RSC consumers.
