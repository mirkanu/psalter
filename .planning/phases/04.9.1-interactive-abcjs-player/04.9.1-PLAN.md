# Phase 4.9.1 (INSERTED): Interactive abcjs Player

## Goal

Replace the current static `AbcRenderer` with a fully interactive music player that displays the soprano melody only, supports playback with current-note highlighting (WebAudio via abcjs synth), key transposition, tempo (BPM) control, and a "show original score" toggle that swaps the live SVG for the original JPEG scan. The player must be wired in everywhere notation is shown today: `/tunes/[id]` and `/psalms/[id]`.

## Requirements

- **PLAYER-01** — Play/Pause button drives abcjs WebAudio playback of soprano melody; current note highlighted in the SVG during playback
- **PLAYER-02** — Transpose dropdown (-6 .. +6 semitones); changing value re-renders the SVG via `visualTranspose`
- **PLAYER-03** — Tempo controls (decrease / display / increase BPM); applied to both visual `defaultTempo` and synth `tempo`
- **PLAYER-04** — "Show original score" toggle swaps the abcjs SVG for the original JPEG (staff or solfège, whichever the user has selected)
- **PLAYER-05** — Mobile responsive: controls collapse/wrap gracefully at 375 px

## Success Criteria (what must be TRUE)

1. On `/tunes/[id]` for a tune with ABC, pressing Play produces audible sound and the note currently being played is visually highlighted in the SVG
2. Changing the transpose dropdown re-renders the SVG with a new key signature; pitched notes shift correctly
3. Pressing the BPM +/- buttons changes the displayed BPM and the audio playback rate on the next play
4. Pressing "Show original score" swaps the SVG for the JPEG scan; pressing again swaps back
5. The same player renders identically on `/psalms/[id]` (replacing the current `AbcRenderer` usage inside `PsalmNotationPlayer`)
6. At 375 px viewport, all controls remain reachable (no horizontal overflow); play/pause + transpose + BPM + show-original all visible and operable
