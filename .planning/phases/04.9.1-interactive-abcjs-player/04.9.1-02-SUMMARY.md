# Phase 4.9.1 Plan 02: AbcPlayer Bug Fixes Summary

Three bugs fixed in the interactive abcjs player: JPEG URLs derived from filesystem, staff/solfège toggle in show-original mode, and lyrics text block below notation.

## What Was Done

### Bug 1: Show Original / Solfège JPEG URLs Always Null

Root cause: `score_jpg_url` and `solfege_jpg_url` DB columns are NULL for all 172 tunes. JPEG files exist on disk at `public/tunes/{slug}-staff-{n}.jpg` and `public/tunes/{slug}-solfege-{n}.jpg`.

Fix: Created `src/lib/tune-jpg-urls.ts` with `tuneNameToSlug()` (lowercased, non-alphanumeric → hyphen, collapsed, trimmed) and `deriveTuneJpgPages()` (probes filesystem for pages 0–7 of each type).

- `tunes/[id]/page.tsx`: replaced null-dependent logic with `deriveTuneJpgPages(tune.name)`, passes `staffPages[0]` and `solfegePages[0]` to `AbcPlayerSection`
- `psalms/[id]/page.tsx`: derives primary tune URLs server-side; enriches all `alternateTunes` with derived URLs; passes `primaryTuneDerivedStaffUrl` / `primaryTuneDerivedSolfegeUrl` as new props to `PsalmTabs`
- `PsalmTabs.tsx`: accepts the two new props and overlays them onto `primaryTune.scoreJpgUrl` / `solfegeJpgUrl` in `activeTune` construction

### Bug 2: Staff/Solfège Toggle in Show-Original Mode

When both `staffJpgUrl` and `solfegeJpgUrl` are non-null and `showOriginal=true`, `AbcPlayer` now renders a small Staff/Solfège sub-toggle above the JPEG. Added `originalMode` state (`'staff' | 'solfege'`) initialised from `initialMode` prop; clicking the sub-toggle switches which JPEG is displayed.

### Bug 3: Lyrics Below Notation

Added optional `lyricsText?: string` prop to `AbcPlayer`. When non-empty and `showOriginal=false`, renders a `<pre data-testid="abc-lyrics">` block below the notation SVG with `whitespace-pre-wrap`, muted colour, centred, `font-sans`. `PsalmNotationPlayer` passes `currentGroup.join('\n\n')` as `lyricsText`.
