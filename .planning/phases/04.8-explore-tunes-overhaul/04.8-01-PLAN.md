# Plan 04.8-01 — /explore: "When you..." section + semibold headings

## Objective

Add a "When you..." section to the /explore page (topics where `topic_type = 'When you...'` in the DB), restructure the Topics section to exclude those entries, and fix the h1 font weight from `font-bold` to `font-semibold` per UI-SPEC.

## Context

DB confirmed: `topic_type` column on `topics` table has 4 distinct values:
- `'Main Topic'` (42 rows) — these are the existing Topics section items
- `'Mood'` (21 rows) — not shown on /explore (displayed on /tunes)
- `'Song Type'` (15 rows) — not shown on /explore
- `'When you...'` (10 rows) — NEW section to add

The current `fetchTopicsWithCounts` fetches all topics with `isNotNull(topics.name)` — this includes Mood, Song Type, and When you... rows mixed in. We need to split this into two fetches: one for `'When you...'` and one for the main topics (Main Topic, Song Type, Mood — or simply exclude When you... from the main list and let the existing section show non-"When you..." topics).

Looking at the reference site (documented in UI-SPEC), the sections are:
1. "When you..." — topics where topicType = 'When you...'
2. Topics — all other topics (Main Topic, Mood, Song Type types)
3. Nave's Topics (existing)
4. Messianic Psalms (existing)
5. Authors (existing)

## must_haves

```yaml
truths:
  - fetchTopicsWithCounts excludes 'When you...' topic_type rows
  - fetchWhenYouTopics returns only topic_type = 'When you...' rows with psalm counts
  - explore/page.tsx renders "When you..." section FIRST, before Topics section
  - "When you..." section uses same grid layout as Topics (grid-cols-2 sm:grid-cols-3 lg:grid-cols-4 gap-2)
  - h1 on explore page uses font-semibold (not font-bold)
  - Separator between every section (When you.../Topics/Naves/Messianic/Authors)
  - Each "When you..." item links to /explore/topics/[slug] (same slug logic as Topics)
```

<action>
In `src/db/queries/explore.ts`:

1. Add `ne` to the drizzle-orm import: `import { eq, asc, desc, count, isNotNull, ne } from "drizzle-orm"`

2. Add new export after `fetchTopicsWithCounts`:

```ts
export const fetchWhenYouTopics = cache(async function fetchWhenYouTopics() {
  return db
    .select({ id: topics.id, name: topics.name, count: count(psalmTopics.psalmId) })
    .from(topics)
    .leftJoin(psalmTopics, eq(psalmTopics.topicId, topics.id))
    .where(eq(topics.topicType, 'When you...'))
    .groupBy(topics.id, topics.name)
    .orderBy(desc(count(psalmTopics.psalmId)))
})
```

3. Update `fetchTopicsWithCounts` to exclude 'When you...' rows by adding a `where` clause with `ne(topics.topicType, 'When you...')` combined with `isNotNull(topics.name)`:

```ts
export const fetchTopicsWithCounts = cache(async function fetchTopicsWithCounts() {
  return db
    .select({ id: topics.id, name: topics.name, count: count(psalmTopics.psalmId) })
    .from(topics)
    .leftJoin(psalmTopics, eq(psalmTopics.topicId, topics.id))
    .where(and(isNotNull(topics.name), ne(topics.topicType, 'When you...')))
    .groupBy(topics.id, topics.name)
    .orderBy(desc(count(psalmTopics.psalmId)))
})
```

Add `and` to the drizzle-orm import.
</action>
