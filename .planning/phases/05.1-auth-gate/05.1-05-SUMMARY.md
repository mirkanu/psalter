## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Stale Next.js build serving 404 for /login**
- **Found during:** Task 1 pre-run
- **Issue:** PM2 `psalter` process was running a build predating Plan 02 (when /login was added). curl http://localhost:3005/login returned 404.
- **Fix:** Ran `npm run build` then `pm2 restart psalter`. Login page returned 200.
- **Commit:** (pre-task infra fix, not separately committed)

**2. [Rule 1 - Bug] playwright-daemon does not support browser.newContext() in --single-process mode**
- **Found during:** Task 1 iterating on script
- **Issue:** The daemon launches Chromium with `--single-process`, which crashes when `browser.newContext()` is called. Multiple context designs all failed with "Target page, context or browser has been closed."
- **Fix:** Rewrote all checks to use the injected `page` directly, using `page.context().clearCookies()` to reset auth state between checks. This correctly simulates unauthenticated visitors for SC2 without a new context.
- **Files modified:** `scripts/uat/auth-gate-uat.js`
- **Commit:** `a52945d`

**3. [Rule 1 - Bug] runPlaywright() return format misread**
- **Found during:** Task 1 first run
- **Issue:** Plan context described `{ result, error }` shape; actual client resolves with `j.result` directly (throws on error). Script had `.error` and `.result` property checks that all returned undefined.
- **Fix:** Removed wrapper object checks; treat the resolved value as the data directly.
- **Files modified:** `scripts/uat/auth-gate-uat.js`
- **Commit:** `a52945d`
