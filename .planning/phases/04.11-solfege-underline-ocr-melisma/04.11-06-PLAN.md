Generate `wave-b.json` containing every tune that:
- Exists in the tunes table.
- Is NOT in samples.json (Wave A exclusion).
- HAS at least one `public/tunes/{slug}-solfege-*.jpg` file (no-image tunes are skipped per D-05).
- HAS a non-null `solfege_ocr_text` column value (proxy for "was previously OCR'd successfully" — these are the ~144 tunes per STATE.md "75/144 tunes populated").

Run a single script to produce the list:

```bash
npx tsx -e "
import 'dotenv/config'; import * as fs from 'node:fs'; import { drizzle } from 'drizzle-orm/postgres-js'; import postgres from 'postgres'; import * as schema from './src/db/schema'; import { isNotNull } from 'drizzle-orm'; import { slugifyTuneName } from './scripts/download-tunes';
const samples = JSON.parse(fs.readFileSync('.planning/phases/04.11-solfege-underline-ocr-melisma/samples.json','utf-8'));
const sampleNames = new Set(samples.map(s =&gt; s.tuneName));
const pg = postgres(process.env.DATABASE_URL!); const db = drizzle({client: pg, schema});
const rows = await db.select({ id: schema.tunes.id, name: schema.tunes.name, meter: schema.tunes.meter }).from(schema.tunes).where(isNotNull(schema.tunes.solfegeOcrText));
const filtered = [];
for (const r of rows) {
  if (sampleNames.has(r.name)) continue;
  const slug = slugifyTuneName(r.name);
  const hasJpg = fs.readdirSync('public/tunes').some(f =&gt; f.startsWith(slug + '-solfege-') &amp;&amp; f.endsWith('.jpg'));
  if (!hasJpg) continue;
  filtered.push({ tuneName: r.name, slug, meter: r.meter });
}
fs.writeFileSync('.planning/phases/04.11-solfege-underline-ocr-melisma/wave-b.json', JSON.stringify(filtered, null, 2));
console.log('wave-b.json written with ' + filtered.length + ' tunes');
await pg.end();
"
```

Expected: 100-140 entries (anything in that range is plausible per STATE.md "144 OCR'd tunes minus 12 Wave A samples minus no-image"). If &lt; 50 → investigate (JPG glob may be broken). If &gt; 160 → investigate (the OCR-text filter may be missing).

Commit wave-b.json to git BEFORE Task 3 so the Wave B input is auditable.
