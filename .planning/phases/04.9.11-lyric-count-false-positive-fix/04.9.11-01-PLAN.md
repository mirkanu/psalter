    Per-tune analysis logic inside `main()`:
    1. Connect DB:
       ```typescript
       if (!process.env.DATABASE_URL) throw new Error('DATABASE_URL not set')
       const pgClient = postgres(process.env.DATABASE_URL!)
       const db = drizzle({ client: pgClient, schema })
       const tunes = await db.select().from(schema.tunes).where(isNotNull(schema.tunes.abcNotation))
       ```
    2. For each tune compute:
       - `n = phrasesForMeter(tune.meter)`; if `n <= 1` push `{ tune: tune.name, meter: tune.meter, skipReason: 'meter-n1' }` and continue
       - `const phrases = tune.abcNotation!.split(/^\s*%\s*PHRASE_BREAK\s*$/m).map(p => p.trim())`
       - If `phrases.length !== n` push `{ tune, meter, skipReason: 'marker-mismatch', expectedPhrases: n, actualPhrases: phrases.length }` and continue
       - For each phrase i: compute `noteHeads[i] = countNoteHeads(phrases[i])`
       - For each phrase i: compute `wTokens[i]` by scanning lines `/^w:/` in `phrases[i]`, stripping the `w:` prefix, splitting on whitespace, filtering empties: `phrases[i].split('\n').filter(l =&gt; /^w:/.test(l.trim())).flatMap(l =&gt; l.replace(/^w:\s*/, '').split(/\s+/).filter(Boolean)).length`
       - `padNeeded[i] = Math.max(0, noteHeads[i] - wTokens[i])`
       - `splitPoints = getSplitPointsForMeter(tune.meter, n)` — may be undefined for non-CM/LM/SM
       - Compute `expectedPerPhrase`: if splitPoints defined, `[splitPoints[0], ...splitPoints.slice(1).map((sp, idx) => sp - splitPoints[idx])]` and append the final phrase expected count as `totalExpected - splitPoints[splitPoints.length - 1]` where `totalExpected` is the meter's syllable total (read from `PHRASES_PER_STANZA` or derive: for CM total=28, LM total=32, SM total=26). Use a small inline lookup table `{ CM: 28, LM: 32, SM: 26 }`; if meter not in table set `expectedPerPhrase = null`.
    3. Classify per-tune root cause (only for tunes where padNeeded[phrases.length-1] > 0):
       - If `expectedPerPhrase` exists and `noteHeads[last] > expectedPerPhrase[last]` → label `'split-mismatch'` (D-05 candidate i: PHRASE_BREAK placed wrong)
       - Else if `noteHeads[last] === expectedPerPhrase?.[last]` and `wTokens[last] < expectedPerPhrase?.[last]` → label `'token-underproduction'` (D-05 candidate iii)
       - Else → label `'unclassified'` (D-05 candidate ii possible, or new mode)
       Push `{ tune: tune.name, meter, n, noteHeads, wTokens, padNeeded, expectedPerPhrase, classification }`.
    4. Aggregate counts per classification: `{ 'split-mismatch': N, 'token-underproduction': N, 'unclassified': N, 'meter-n1': N, 'marker-mismatch': N }`.
