<objective>
Mechanical sweep across `src/components/` and `src/app/**/page.tsx` to add `:active` press-feedback Tailwind classes to every `<Link>`, plain `<button>`, and card-like `<a>` wrapper that lacks them. Two class patterns per UI-SPEC §4:

| Element type | Class to add |
|--------------|--------------|
| `<Link>` (Next.js) | `active:bg-muted active:translate-y-px transition-all duration-75` |
| `<button>` (non-shadcn) | `active:bg-muted active:translate-y-px transition-all duration-75` |
| `<a>` plain anchor | Same as `<Link>` |
| Card-link wrappers | `active:bg-muted active:scale-[0.98] transition-transform duration-75` |

Exclusions (per UI-SPEC §4): elements inside `<Dialog>`/`<Sheet>`/`<Popover>` (base-ui handles), `<Button>` shadcn primitive (already has `active:translate-y-px`), disabled elements (already styled).

Purpose: Every clickable element on the site gives an instant visual confirmation of press. Without this, the only feedback on click is the navigation itself, which feels unresponsive especially on mobile.
Output: Modified `.tsx` files across `src/components/` and `src/app/`. No new files.
</objective>
