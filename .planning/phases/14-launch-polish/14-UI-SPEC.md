# Phase 14 — UI Design Contract

> Visual and interaction contract for the Launch Polish phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> Phase 14 is a POLISH phase on a largely-built app (Phases 1–13 shipped). The design system already exists in code; this spec LOCKS the established conventions and specifies only the new polish surfaces: OG image template, styled 404 page, skeletons for search/explore/daily/homepage, `:active`/pending click feedback, and a real favicon.

## Spacing Scale

Established Tailwind 4 scale (no phase-specific exception table — locked from existing UI):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`, `p-1`) | Icon gaps, inline padding, dense grid cells |
| sm | 8px (`gap-2`, `p-2`) | Compact element spacing (button heights `h-7`/`h-8`) |
| md | 16px (`gap-4`, `p-4`) | Default element spacing (Dialog padding, card inner) |
| lg | 24px (`gap-6`, `py-6`) | Section padding inside a page |
| xl | 32px (`gap-8`, `py-8`) | Layout gaps between major page regions |
| 2xl | 48px (`py-12`) | Major section breaks; homepage hero region |
| 3xl | 64px (`py-24`) | Page-level 404 spacing only |

**Exceptions (locked from existing UI):**
- SiteHeader height: ~56px (not in 4-px scale — sticky bar with `pt-[env(safe-area-inset-top)]` for iOS)
- Glass bottom bar: `h-11`/`h-13` (44/52px) — fixed mobile chrome
- Icon-only buttons: `size-8` (32px) minimum desktop, `size-9` on lg
- 404 page uses `py-24` (only surface that intentionally extends past 48px)

### 4. Click-feedback states — `<Link>`, `<Button>`, card-like links

Currently `<Button>` already has `active:not-aria-[haspopup]:translate-y-px` (1px press-down) but `<Link>` (Next.js) and other interactive `<a>` / `<button>` elements only have `:hover` styling. Phase 14 adds `:active`/pending feedback to all clickable elements that lack it.

**Contract:** Every clickable element gives immediate visual feedback on press within one frame.

**Patterns to apply (use existing Tailwind utilities — no new CSS):**

| Element type | Class to add | Visual result |
|--------------|--------------|---------------|
| `<Link>` (Next.js) | `active:bg-muted active:translate-y-px transition-all duration-75` | Flash to muted bg + 1px down-press |
| `<button>` (non-shadcn) | `active:bg-muted active:translate-y-px transition-all duration-75` | Same as Link |
| `<a>` plain anchor | Same as Link | Same |
| Card-link wrappers (e.g. `PsalmListingGrid` psalm boxes) | `active:bg-muted active:scale-[0.98] transition-transform duration-75` | Brief scale-down (cards need more visual confirmation than inline links) |

**Where to apply:** All `<Link>` and `<button>` elements in `src/components/` and `src/app/*/page.tsx` EXCEPT:
- Anything inside `<Dialog>`, `<Sheet>`, `<Popover>` (those use base-ui's built-in press states)
- The `<Button>` shadcn primitive (already has `active:translate-y-px`)
- Disabled elements (already styled with `pointer-events-none opacity-50`)

**Scope guidance for executor:** Apply class additions mechanically via search-and-replace across these directories. The goal is uniform feel, not exhaustive audit. Audit pass at the end checks that psalm boxes, tune cards, search result rows, and primary CTAs all flash.

### 5. Favicon

Replace `public/favicon.ico` (currently default Next.js icon) with a real favicon.

**Approach:** Generate a single SVG favicon at `src/app/icon.svg` using the same `lucide-react` `Music` glyph used on the 404 page, sized 32x32 with the site's primary background. Next.js 15 auto-detects `app/icon.svg` and emits the `<link rel="icon">` tag — no manual `metadata.icons` config needed.

**Locked design:**
- 32x32 viewBox, dark `oklch(0.205 0 0)` square background, white `Music` glyph centered, 2px corner radius (matches `--radius-sm` aesthetic).
- Also drop a 180x180 `apple-touch-icon.png` at `src/app/apple-icon.png` (Next.js 15 file convention) with the same glyph but inverted (white background, dark icon) — iOS expects light-on-light for home-screen icons, the `appleWebApp.capable: true` in `layout.tsx` means iOS will use this for "Add to Home Screen".
