## Sampling Rate

- **After every task commit:** Run quick suite (`test-04.9.4-quick.js` — SC1, SC4, SC6 at 375px only)
- **After every plan wave:** Run full suite (all 6 SCs at 375 / 768 / 1024)
- **Before `/gsd-verify-work`:** Full suite must be green
- **Max feedback latency:** 30s (quick), 120s (full)

Both scripts SKIP gracefully (exit 0 with `SKIP:` log) when the dev server is not running on port 3005, so they never block commits in offline mode.
