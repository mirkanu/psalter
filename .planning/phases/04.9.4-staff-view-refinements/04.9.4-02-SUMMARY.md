**Replaced the legacy `PsalmActionsFAB` + `TuneSubBar` with three new components (`GlassBottomBar`, `PlayMiniBar`, `GearDrawer`), lifted `isPlaying` and `currentStanza`/`totalStanzas` to `SingingView`, and refreshed the `loading.tsx` skeleton to match the new chrome.**

## Accomplishments

- `GlassBottomBar` renders persistent fixed glass strip with A−/A+ left group, live stanzas indicator (`Stanza N / M` via `data-stanzas-indicator`), view radiogroup, gear, play.
- Tour-target hooks `data-tour-target="view-controls"` and `data-tour-target="play-button"` ready for the onboarding tour plan.
- `PlayMiniBar` slides in from below the glass bar on first Play tap (two-phase mount with `requestAnimationFrame` between mount and visible), reduced-motion fallback (opacity only), focus-safe hidden state via `display:none` after exit.
- `GearDrawer` Sheet side="bottom" carries View + About sections; **no audio controls** (audio is owned by `PlayMiniBar`).
- `AbcAudioControls` accepts optional `isPlaying` + `onPlayingChange` for controlled-by-parent use; legacy uncontrolled mode preserved (no behaviour change for any caller without props).
- `NotationRenderer` reports `onStanzaChange(current, total)` (1-indexed current) on mount and on every change; `SingingView` lifts both values and forwards them to the GlassBottomBar.
- Body height calc updated to `100dvh - 104px` mobile / `100dvh - 116px` md, with `pb-14 md:pb-15` so content scrolls clear of the fixed glass bar.
- `loading.tsx` matches new chrome: single top bar skeleton (two-slot centre), notation body, glass bottom strip (`data-glass-bottom-bar-skeleton`).

## Decisions Made

- Hybrid controlled/uncontrolled `AbcAudioControls` API — lets `PlayMiniBar` drive play state from `SingingView` without touching any other call-site (zero-regression).
- `prevControlledRef` guard on the controlled-flip effect prevents recursion when the synth's own callbacks update the parent and the parent re-renders us with the new value.
- 1-indexed `onStanzaChange` payload so consumers render the template literal directly.
- Empty-string stanza indicator when data is unknown (preserves layout, no visual placeholder).
- `requestAnimationFrame` between `setMiniBarMounted(true)` and `setMiniBarVisible(true)` so the CSS transition has a `translate-y-full` starting frame to animate from.
