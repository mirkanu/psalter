**Fix applied:** `tests/e2e/explore-rebuild.spec.ts` lines 215-232 now assert the inverse: the Date B.C. `<th>` must be present in the DOM AND `isVisible()` must return `true`. If it is not visible, the test fails with "should be visible with horizontal scroll".

**Code evidence (spec lines 215-232):**
- Navigates to /explore at 375px viewport
- Queries `th:has-text("Date B.C.")` 
- Asserts `isVisible() === true` → PASS
- On failure: "column is hidden — should be visible with horizontal scroll"

**Code evidence (AuthorsTable.tsx lines 69-80):**
- Table wrapper: `className="overflow-x-auto rounded-md border border-border"` — horizontal scroll enabled
- Date B.C. `<th>` at line 75: `className="w-24 px-3 py-2 font-semibold"` — no `hidden` class
- Occasion `<th>` at line 80: `className="px-3 py-2 font-semibold"` — no `hidden` class
- No `hidden sm:table-cell` on any `<th>` or `<td>` elements

The spec and the implementation are now consistent. The gap is closed.
