## What Was Built

### Task 1: AuthorsTable

`src/components/AuthorsTable.tsx` — client component (`'use client'`) that:
- Accepts `{ psalms: PsalmWithAuthorData[] }` where each psalm has `id`, `author`, `dateBC`, `occasion`
- Renders 8 filter pills (Asaph, David, Ethan the Ezrahite, Heman the Ezrahite, Moses, Solomon, Sons of Korah, Unknown) — toggleable, deselecting returns to "all"
- Sorts by `dateBC` ascending, nulls last
- Table with 4 columns: Psalm, Author (colored pill), Date B.C. (hidden on mobile), Occasion (hidden on mobile, truncated at 60 chars)
- Row click navigates to `/psalms/[id]` via `useRouter`
- Attribution line: "Sorted from earliest date; some data is conjecture. Source: blueletterbible.org"

### Task 2: Naves Detail Page Rebuild

`src/app/explore/naves/[slug]/page.tsx` rebuilt to:
- Import `fetchNavesSubTopics` instead of `fetchPsalmDetailsByNavesTopic`
- Render sub-topic groups: each entry gets an `<h2>` (sub_topic ?? 'General'), then verse links with optional quotation text indented beneath
- Fix h1 from `font-bold` to `font-semibold` per UI-SPEC typography rule
- Keep all existing infrastructure: `export const dynamic = 'force-dynamic'`, `buildNavesSlugMap`, `generateStaticParams`, `generateMetadata`, breadcrumb
