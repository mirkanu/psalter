## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Drizzle empty-SET error when updating psalm dateBC/occasion**
- **Found during:** Task 1 execution
- **Issue:** `db.update(schema.psalms).set({ dateBC: null, occasion: 'text' })` generated `UPDATE psalms SET WHERE` — Drizzle ORM silently drops null values from `.set()`, producing an invalid empty SET clause.
- **Fix:** Replaced with explicit `if/else if` branches to call `.set({ dateBC })`, `.set({ occasion })`, or `.set({ dateBC, occasion })` depending on which values are non-null.
- **Files modified:** scripts/migrate-explore-04-12.ts
- **Commit:** 664b329
