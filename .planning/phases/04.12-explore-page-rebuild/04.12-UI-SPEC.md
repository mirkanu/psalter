## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap, badge padding |
| sm | 8px | Topic pill gap (`gap-2`), compact row gap |
| md | 16px | Section inner padding, card padding |
| lg | 24px | Section header bottom margin, card gap |
| xl | 32px | Section top/bottom padding |
| 2xl | 48px | `my-8` separator spacing between major sections |
| 3xl | 64px | Page top padding on desktop (`py-8` = 32px on mobile, `md:py-8`) |

Exceptions:
- Author filter button row: `gap-2` (8px) between pills
- Anchor nav (if rendered): `gap-4` (16px) between links
- Touch targets: minimum 44px height on all interactive elements (`min-h-[44px]`)

## Color

Pre-populated from globals.css `:root` oklch tokens.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `oklch(1 0 0)` — white | Page background, card/popover background |
| Secondary (30%) | `oklch(0.97 0 0)` — near-white | Muted surfaces (`--muted`), topic pill hover state (`hover:bg-muted`), secondary badge background |
| Accent (10%) | `oklch(0.205 0 0)` — near-black | Accent reserved for: anchor nav active indicator, author pill text color on selection, hover border hint (`hover:border-primary/30`) |

Accent reserved for ONLY:
1. Active state on sticky anchor nav (if implemented): left border or underline on current section
2. Author name pill text (`text-primary`) when the filter is selected/active
3. Hover border accent on topic links (`hover:border-primary/30`)

Author pill colors — use `bg-muted text-foreground` for inactive, `bg-primary text-primary-foreground` for active selected filter. Do NOT introduce new color tokens for author pills.

## Section-by-Section Interaction Contracts

### Section 1 — When you're feeling...

- Layout: `grid grid-cols-2 sm:grid-cols-3 lg:grid-cols-4 gap-2` (inherits existing pattern)
- Each item: `inline-flex items-center justify-between px-3 py-2 rounded-md border border-border text-sm hover:bg-muted hover:border-primary/30 transition-colors min-h-[44px]`
- Count badge: `<Badge variant="secondary">N psalms</Badge>`
- Link target: `/explore/topics/[slug]` (existing route)
- No changes to existing render — data source already correct (`topic_type = "When you..."`)

### Section 2 — By Theme

- Section header: `<h2>By Theme</h2>`
- Three sub-groups rendered in order: **Main Topic** (42) | **Mood** (21) | **Song Type** (15)
- Each sub-group: `<h3 className="text-base font-medium mb-2 mt-4">Main Topic</h3>` then the same pill grid
- Grid: `grid grid-cols-2 sm:grid-cols-3 lg:grid-cols-4 gap-2` (same as When you...)
- Link target: `/explore/topics/[slug]` (same existing route)
- No new routes required — purely a UI split of existing data

### Section 3 — In the NT

Two distinct sub-sections separated by a `<Separator className="my-4" />`:

**3a — Quoted in NT**
- Header: `<h3 className="text-base font-medium mb-2">Quoted in the New Testament</h3>`
- Displays sub-topics from `verse_naves_topics WHERE naves_topic = "Quotations and Allusions"`
- Each sub-topic: expandable/collapsible row showing sub_topic label + list of psalm verse references + quotation text
- Collapse pattern: uses `<details>/<summary>` or a client-side accordion. Use shadcn Collapsible (already installed via shadcn) — `import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@/components/ui/collapsible"` — install if not present
- Summary row: sub_topic text (left) + verse count badge (right), `ChevronDown` / `ChevronUp` icon from lucide
- Expanded content: list of verse references + quotation text in `text-sm text-muted-foreground italic`
- Link each reference: `/psalms/[psalmId]`

**3b — Messianic By Topic**
- Header: `<h3 className="text-base font-medium mb-2">Messianic by Topic</h3>`
- Lists Nave's topics where `naves_topics.messianic IS NOT NULL` (values: "Primarily Messianic", "Not Messianic but glimpses (Highlights)", "Not Messianic; parallel situations (Parallels)")
- Group by classification label as sub-heading: `<p className="text-xs uppercase tracking-wide text-muted-foreground mb-1">Primarily Messianic</p>`
- Topic pills: same `border rounded-md px-3 py-2 text-sm` style; link to `/explore/naves/[slug]`
- Existing "By Psalm" link retained as: `<Link href="/explore/messianic">All Messianic Psalms — 18 psalms →</Link>` as a single full-width row card

### Section 4 — Other Topics (Nave's Topics)

- Inherits existing `<NavesExpand>` pattern for collapsed flat list
- Enhanced: clicking a Nave's topic navigates to `/explore/naves/[slug]` which is rebuilt to show sub-topics grouped, not a flat psalm list
- The `/explore/naves/[slug]` detail page layout:
  - `<h1>Topic Name</h1>` — standard page h1
  - For each sub_topic group: `<h2 className="text-lg font-semibold mb-2">Sub-topic label</h2>` then a list of verse references + quotation text
  - Verse reference: `<Link href="/psalms/[id]">Psalm N:V</Link>` — `text-sm font-medium`
  - Quotation text: `<p className="text-sm text-muted-foreground italic ml-4">quotation</p>`

### Section 5 — Authors

**This is the most complex new component — a client-side filterable table.**

- Component: `<AuthorsTable />` — `'use client'` component in `src/components/AuthorsTable.tsx`
- Source attribution (below section header, above filter row): `<p className="text-sm text-muted-foreground mb-4">Sorted from earliest date; some data is conjecture. Source: blueletterbible.org</p>`

**Filter buttons (8 authors):**
- Row: `flex flex-wrap gap-2 mb-4`
- Each filter pill: `<button>` with variant toggled — inactive: `border border-border rounded-full px-3 py-1 text-sm bg-background hover:bg-muted`, active: `bg-primary text-primary-foreground rounded-full px-3 py-1 text-sm`
- Authors: Asaph / David / Ethan the Ezrahite / Heman the Ezrahite / Moses / Solomon / Sons of Korah / Unknown
- "All" implicit: when no filter selected, show all 150 psalms
- Client state: `useState<string | null>(null)` for selected author; null = show all

**Table columns:**
| Column | Width | Notes |
|--------|-------|-------|
| Psalm # | 80px | Integer, right-aligned, `font-mono text-sm` |
| Author | 160px | Coloured pill — unique background per author (see pill colors below) |
| Date B.C. | 100px | Integer from `psalms.date_bc`, display as "~N B.C.", null = "Unknown" |
| Occasion | auto | Text from `psalms.occasion`, truncate at 60 chars with title attr for full text |

**Author pill colors** — use a deterministic map, no CSS custom vars needed:
- David: `bg-blue-100 text-blue-800`
- Asaph: `bg-purple-100 text-purple-800`
- Sons of Korah: `bg-green-100 text-green-800`
- Moses: `bg-amber-100 text-amber-800`
- Solomon: `bg-yellow-100 text-yellow-800`
- Ethan the Ezrahite: `bg-rose-100 text-rose-800`
- Heman the Ezrahite: `bg-orange-100 text-orange-800`
- Unknown: `bg-muted text-muted-foreground`

**Default sort:** ascending `date_bc` (earliest first); nulls last. Client-side sort — no route change needed.

**Responsive:** On mobile (`< sm`), hide the "Date B.C." and "Occasion" columns; show only Psalm # and Author pill. Use Tailwind responsive visibility: `hidden sm:table-cell` on those columns.

**Table wrapper:** `<div className="overflow-x-auto rounded-md border border-border">` + `<table className="w-full text-sm">` + standard `<thead>` / `<tbody>` with `hover:bg-muted` on rows.

Row link: entire row clickable via `<tr onClick={() => router.push('/psalms/[id]')} className="cursor-pointer hover:bg-muted transition-colors">`.

### Section 6 — Heidelberg Catechism

- Section header: `<h2 className="text-xl font-semibold mb-1">Heidelberg Catechism</h2>`
- Subtitle: `<p className="text-sm text-muted-foreground mb-4">97 references across 35 questions</p>`
- Layout: list of Q numbers grouped as collapsible rows (same shadcn Collapsible pattern as Section 3a)
- Each group row: `Question N` (left) + `N verses` badge (right) + ChevronDown icon
- Expanded: list of verse references, each as `<a href={url} target="_blank" rel="noopener noreferrer">` linking to the external Heidelberg resource + `ExternalLink` icon from lucide (12px, inline)
- Verse reference text: `Psalm N:V — Question N` format in `text-sm`
- Groups: 35 distinct question numbers, sorted ascending

## Page-Level Layout Contract

### Sticky Anchor Navigation

A sticky anchor nav appears at the top of the page (below the SiteHeader) when the user scrolls past the page h1. This orients users in the long single-scroll page.

- Component: `<ExploreAnchorNav />` — `'use client'` using IntersectionObserver to detect active section
- Placement: `sticky top-[64px] z-10 bg-background/95 backdrop-blur-sm border-b border-border`
- Height: 40px (`h-10`)
- Items (in order): When you're feeling | By Theme | In the NT | Other Topics | Authors | Catechism
- Item style: `text-sm px-3 py-2 text-muted-foreground hover:text-foreground transition-colors`
- Active item: `text-foreground font-medium border-b-2 border-primary -mb-px` (underline indicator)
- Mobile: horizontal scroll (`overflow-x-auto flex whitespace-nowrap`) — all 6 labels on one scrollable row
- This is optional if complexity is judged too high by planner — fallback is no anchor nav

### Page Layout Wrapper

```
max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 py-6 md:py-8
```

- Sections separated by `<Separator className="my-8" />` (inherits existing pattern)
- Each section: `<section id="[anchor-id]">` with the anchor ID matching the nav links
  - `when-you` / `by-theme` / `in-the-nt` / `other-topics` / `authors` / `catechism`
