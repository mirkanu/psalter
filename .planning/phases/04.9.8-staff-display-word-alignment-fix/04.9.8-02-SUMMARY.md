# Phase 04.9.8 Plan 02: Staff Display Word Alignment Fix — Implementation Summary

**One-liner:** Live DB migration inserting 3 PHRASE_BREAK markers per CM/LM/SM tune using note-head counting, with phrasesForMeter doubled (CM 2→4, DCM 4→8) and z2 trailing-rest defensive filter, deployed and serving 200s.

## What Was Built

Three coordinated changes deployed in sequenced order to fix staff word alignment:

1. **`insertPhraseBreaks` upgraded with note-head counting** (`scripts/annotate-phrase-breaks.ts`) — New `getSplitPointsForMeter` helper returns exact note-head split points per meter (CM: [8,14,22], LM: [8,16,24], SM: [6,12,20], DCM: [8,14,22,30,36,44,52]). The insertion loop accumulates note heads per music line and inserts `% PHRASE_BREAK` after crossing each threshold. Old 100th `w:` line stripping added for idempotency.

2. **`phrasesForMeter` constants updated** (`src/lib/abc-phrase-meter-map.ts`) — CM/LM/SM/8.7.8.7/7.6.7.6 changed from 2 to 4; DCM/DLM/DSM from 4 to 8. This aligns one staff row per metrical line.

3. **z2 defensive filter** (`src/lib/split-music-into-sublines.ts`) — Extracted `splitMusicIntoSubLines` to a testable module. Filter excludes bare rest pseudo-bars (`/^\s*[zxZ]\d*\s*/`) from measure counting, fixing the 5 tunes with trailing `z2` rests (Arnold, Crediton, New Britain, St. Andrew, St. Mary).
