# Phase 04.9.8 Plan 01: Phrase-Break Audit Summary

**One-liner:** Read-only audit of 144 tunes' abc_notation enumerating PHRASE_BREAK counts, note-head-per-phrase arrays, and z2-trailing-rest flags as source-of-truth JSON for Plan 02 migration.

## What Was Built

### Task 01-01: Audit Script with Note-Head Counting (COMPLETE — commit 817b55e)

**New export added to `scripts/annotate-phrase-breaks.ts`:**
- `countNoteHeads(abc: string): number` — counts note heads in an ABC fragment, excluding rests, chords (counted as 1 each), grace notes, text annotations, decorations, and tied-continuation notes.

**New file `scripts/audit-phrase-breaks.ts`:**
- `auditTune({ name, meter, abcNotation })` — pure function exported for unit testing. Computes expected vs actual PHRASE_BREAK count, note heads per phrase, z2 trailing rest detection, and known-z2-bug flag.
- `main()` — queries `tunes` table, maps all rows through `auditTune`, sorts (MISMATCH first), writes `scripts/output/phrase-break-audit.json`, prints stdout table.

**New test file `scripts/audit-phrase-breaks.test.ts`:**
- 13 tests covering: CM OK/MISMATCH, noteHeadsPerPhrase array structure, z2 trailing rest detection, all 5 known-z2-bug tune names, null meter, totalNoteHeads sum.
