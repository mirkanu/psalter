### `src/hooks/useSwipeGesture.ts` (NEW hook, event-driven)

**Analog (hook file shape / SSR-guard convention):** `src/hooks/useMediaQuery.ts` (full file, 27 lines) and `src/hooks/useLocalStorage.ts` (21 lines)

**File shape to mirror exactly** (`src/hooks/useMediaQuery.ts`, full file):
```typescript
'use client'

import { useEffect, useState } from 'react'

export function useMediaQuery(query: string): boolean {
  const [matches, setMatches] = useState(false)

  useEffect(() => {
    if (typeof window === 'undefined' || !window.matchMedia) return
    const mql = window.matchMedia(query)
    setMatches(mql.matches)
    const listener = (e: MediaQueryListEvent) => setMatches(e.matches)
    mql.addEventListener('change', listener)
    return () => mql.removeEventListener('change', listener)
  }, [query])

  return matches
}
```
`useSwipeGesture` should follow the same shape: `'use client'` directive, a single exported hook function, `useEffect`-based listener attach/detach with a guard for `typeof window === 'undefined'`, returning either a ref-callback or accepting a `RefObject` param (executor's call — no existing ref-accepting hook in this codebase to copy verbatim, but the SSR-guard-first-line convention is established across both existing hooks).

**Threshold/gesture logic — no in-house analog; use UI-SPEC's prescriptive defaults verbatim** (UI-SPEC "Component Spec: Swipe Gesture" section, already fully specified — copy these constants directly, do not re-derive):
- Direction lock: horizontal only if `|dx| > |dy| * 1.5` after first ~10px of movement.
- Commit threshold: `|dx| >= 50px` at touch-end.
- No rubber-band/bounce animation at boundaries (no-op, matches `GlassBottomBar`'s existing `disabled` no-op prev/next behavior).

**Event listener attach/cleanup style to mirror** (`SingingView.tsx` lines 772-780, the scroll-hide effect's own attach/detach, as the nearest same-file event-listener precedent even though it's not itself a hook):
```typescript
main.addEventListener('scroll', handleScroll, { capture: true, passive: true })
return () => {
  main.removeEventListener('scroll', handleScroll, { capture: true } as EventListenerOptions)
  ...
}
```
Use `{ passive: true }` for `touchstart`/`touchmove` (no `preventDefault()` needed per UI-SPEC's explicit instruction not to break vertical scroll), non-passive only if a future need arises to block scroll during an active horizontal drag (not required by this phase's spec).
