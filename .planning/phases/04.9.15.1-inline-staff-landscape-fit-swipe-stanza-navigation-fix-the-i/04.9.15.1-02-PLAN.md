  <behavior>
    - Given a committed leftward swipe (touchstart at x=200, touchend at x=140, small dy) → onSwipeLeft called once, onSwipeRight not called.
    - Given a committed rightward swipe (x=140 → x=210, small dy) → onSwipeRight called once.
    - Given a drag with |dx| < 50px → neither callback called (below commit threshold).
    - Given a mostly-vertical drag (dx=60, dy=200 so |dx| < |dy| * 1.5) → neither callback called (direction lock rejects it).
    - Given enabled: false → no listeners attached, no callbacks fire.
  </behavior>
  <action>
    Create `src/hooks/useSwipeGesture.ts`, header `'use client'`. Mirror `useMediaQuery.ts`'s
    file shape: single exported function, one `useEffect`, SSR/`typeof window === 'undefined'`
    guard, cleanup on return.

    Signature (exact, per interfaces above):
    ```typescript
    export function useSwipeGesture(
      ref: RefObject<HTMLElement | null>,
      { onSwipeLeft, onSwipeRight, enabled = true }: SwipeOptions,
    ): void
    ```

    In the effect:
    - Guard: `if (!enabled) return` and `if (typeof window === 'undefined') return` and `const el = ref.current; if (!el) return`.
    - Track `startX`, `startY`, and a `locked: 'none' | 'horizontal' | 'vertical'` state in closure vars reset on `touchstart`.
    - `onTouchStart`: record `startX = e.touches[0].clientX`, `startY = e.touches[0].clientY`, `locked = 'none'`.
    - `onTouchMove`: compute `dx = e.touches[0].clientX - startX`, `dy = e.touches[0].clientY - startY`. Once `Math.hypot(dx, dy) > 10` and `locked === 'none'`, set `locked = Math.abs(dx) > Math.abs(dy) * 1.5 ? 'horizontal' : 'vertical'`. Do NOT call `preventDefault()` (UI-SPEC: vertical scroll-hide must keep working).
    - `onTouchEnd`: read final delta from `e.changedTouches[0]`. Only act if `locked === 'horizontal'` AND `Math.abs(dx) >= 50`. If `dx < 0` → `onSwipeLeft?.()`; if `dx > 0` → `onSwipeRight?.()`.
    - Attach all three with `{ passive: true }`. Remove all three in the cleanup return.
    - Effect deps: `[ref, enabled, onSwipeLeft, onSwipeRight]`.

    Add the constants inline as named locals for clarity: `const COMMIT_PX = 50`, `const DIR_LOCK_RATIO = 1.5`, `const DIR_LOCK_START_PX = 10`.

    Also create `src/hooks/useSwipeGesture.test.ts` (vitest, matching existing test conventions
    — see vitest.config.mts / other *.test.ts) covering all five <behavior> cases. Render the
    hook against a real detached `<div>` element ref and dispatch synthetic `TouchEvent`s (or
    a minimal touch-event stub with `touches`/`changedTouches` arrays of `{clientX, clientY}`).
  </action>
