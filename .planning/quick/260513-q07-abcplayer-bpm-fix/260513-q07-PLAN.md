# Quick Task 260513-q07: Fix AbcPlayer BPM

## Goal

Changing BPM in the audio player has no effect on playback speed or highlight sync.
Key change works. Two bugs in `onPlay` introduced by commit `aa8a8fc`.

## Root Cause Analysis

### Bug 1 — `millisecondsPerMeasure` in wrong position

`CreateSynth.init()` reads `millisecondsPerMeasure` from the **top-level** object:
```js
// abcjs source (create-synth.js:125):
self.millisecondsPerMeasure = options.millisecondsPerMeasure ? options.millisecondsPerMeasure : ...
// where `options` = the argument passed to init(), NOT the nested `.options` key
```

Commit `aa8a8fc` moved it inside `options: {}`, so it's now at `options.options.millisecondsPerMeasure`
— which abcjs never reads. The synth falls back to the tune's own Q: tempo.

### Bug 2 — `TimingCallbacks` ignores `millisecondsPerMeasure` param

`TimingCallbacks` reads `params.qpm` (not `params.millisecondsPerMeasure`) to control highlight timing:
```js
// abcjs source (abc_timing_callbacks.js:4):
self.qpm = params.qpm ? parseInt(params.qpm, 10) : null;
```
Passing `millisecondsPerMeasure` has no effect. Highlights always fire at the tune's own BPM.

## Tasks

### Task 1 — Fix `onPlay` in `AbcPlayer.tsx`

**File:** `src/components/AbcPlayer.tsx`

Change `onPlay` callback (lines ~208–237):

**Before (broken):**
```js
await synth.init({
  visualObj: visualObjRef.current,
  options: {
    soundFontUrl: SOUNDFONT_URL,
    midiTranspose: transpose,
    millisecondsPerMeasure: visualObjRef.current.millisecondsPerMeasure?.(bpm),
  },
})
...
const timing = new abcjs.TimingCallbacks(visualObjRef.current, {
  eventCallback: highlightEvent,
  millisecondsPerMeasure: visualObjRef.current.millisecondsPerMeasure?.(bpm),
})
```

**After (fixed):**
```js
await synth.init({
  visualObj: visualObjRef.current,
  millisecondsPerMeasure: visualObjRef.current.millisecondsPerMeasure?.(bpm),  // top-level
  options: {
    soundFontUrl: SOUNDFONT_URL,
    midiTranspose: transpose,
  },
})
...
const timing = new abcjs.TimingCallbacks(visualObjRef.current, {
  eventCallback: highlightEvent,
  qpm: bpm,  // qpm controls highlight timing rate, not millisecondsPerMeasure
})
```

**Verify:** Change BPM to 120, press Play — audio is noticeably faster. Blue highlight dot follows the faster tempo. Reset to default — returns to Q: tempo. Key change still works.
